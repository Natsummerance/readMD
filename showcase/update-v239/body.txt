用惯了 Markdown 的朋友，通常对软件有两点硬性要求：第一必须纯本地，数据绝不能随便上云；第二启动要快，绝不能点开等半天。

但很多单机 Markdown 工具功能又极其单一，一旦遇到要改两页 PDF、看文档双链关系、或者跑一段示例代码，就不得不打开好几个重量级软件来回倒腾。

ReadMD 刚推送的 v2.3.9 大版本更新，没有做那些华而不实的微调，而是把整套功能架构做了深度解耦，在保持纯单机的前提下把生产力直接拉满。

首先是桌面伴读与快捷入口。我们在单机阅读器里放进了一套桌面宠物系统，包含 Arch-Chan Live2D 和 73 款免配置的精灵图。除了呼吸动效和打字反馈，它还是一个直觉式的文件入口：你随手把本地的 Markdown、PDF 或者 Word 拖动扔到桌宠身上，后台就会自动触发解析并在阅读器里秒级打开。桌宠和主程序是双向进程隔离的，就算遇到异常文档也不会把阅读器拖死。

第二是直接在本地编辑 PDF。内置的原生矢量引擎可以直接修改 PDF 文本层，带有严格的零污染差分校验，绝不会碰到周边的底纹和公章，写前还会自动备份。配合扩展后的 21 项 FastMCP 工具，外部的 Claude Desktop 或 Cursor 能直接调用接口帮你自动化质检和修改 PDF。

第三是自带 3D 知识图谱与双链引擎。基于本地 SQLite WAL 构建，扫完一篇长文只要不到两毫秒。你写的每一处维基双链都会实时投影成三维立体引力场图谱，支持旋转缩放和邻居节点筛选，旁边还配了防覆写的反向链接抽屉。

第四是彻底摆脱了微软 Office 依赖。很多老旧的 .doc 文件以往必须装了 Office 才能转，这次我们用纯 Python 直接读二进制流，配合表格聚类算法，遇到复杂的跨行跨列表格也能完整还原成干净的 Markdown 表格。

第五是多语言代码块在文档里就地运行。Python、JavaScript、Shell、R 和 Rust 都能直接点运行，画出来的图表会自动回填到文章正文里。底层挂了系统级的进程作业限制，遇到死循环十秒强制掐断，绝不锁死电脑。

最关键的是，加了这么多功能，核心安装包反而彻底瘦身到了 28.2MB。因为我们把 OCR 和语音转写等重型模块全拆到了独立沙箱里按需加载，日常打开 Markdown 只要 2 秒，窗口建立只需要 85 毫秒。
