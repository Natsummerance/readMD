平时写文档或看代码，很多人坚持用纯本地 Markdown，无非图两个心安：隐私数据不往云端传，随手点开就要能看，绝不等进度条转圈。

但单机工具往往走另一个极端：功能太素。偶尔要改两行合同 PDF、理一下长文双链、或者随手跑一段示例代码，桌面就得开一排笨重的专用软件，切来切去相当折磨。

ReadMD 这次升到 v2.3.9，把整套架构做了模块解耦，在纯本地、不联网的前提下把这些高频刚需全补齐了。

最好玩也最实用的是屏幕角落的桌宠。除了 Arch-Chan Live2D 和 73 款免配置精灵图的呼吸动效，它其实是个极简的文件投递箱。桌面上随手抓起一份 Markdown、学术 PDF 甚至老旧 Word，往小宠物身上一扔，后台秒级完成解析并在阅读器里展开。两者在底层是独立进程，就算丢进去一份格式稀烂的大文件，阅读器主窗口也稳如泰山。

本地改 PDF 也变轻松了。内置的矢量引擎能直接修改 PDF 文本层，带有零污染差分校验，周边的公章、底纹连一个像素都不会碰歪，保存前会自动生成安全备份。要是想批量处理，接上 21 项 FastMCP 工具，Cursor 或 Claude Desktop 也能调接口帮你自动化巡检与改写。

长文整理方面，自带了基于本地 SQLite WAL 的双链引擎，扫完整篇文档只要不到两毫秒。平时随手记的维基链接，会实时生成可交互的三维立体引力场星系图，鼠标滚轮一滑就能漫游节点，旁边还配了防覆写的反向链接抽屉。

碰到别人发来的旧版 doc 格式，完全不用装微软 Office。软件用纯 Python 直接解析二进制流，加上表格聚类算法，跨行跨列的复杂表格也能无损还原成干净的 Markdown 表格。

写技术文档时，Python、JavaScript、Shell、R 和 Rust 代码块点一下直接就地运行，生成的图表会自动嵌回正文。底层设有系统级作业限制，真遇到死循环代码十秒内强制掐断，不用担心卡死机器。

功能加了这么多，核心安装包反而压缩到了 28.2MB。因为 OCR 和语音转写等大块头组件全被剥离到了独立沙箱按需加载。日常打开文档只要 2 秒，冷启动窗口建立 85 毫秒。

纯本地、零遥测、秒级响应，本地写作也能兼顾舒服和省心。
