v2.3.7-beta.1 · 不用重做PPT，Markdown直接放映

#36 · outcome-led__36 · prerelease

ReadMD 让同一份 Markdown 从阅读、编辑直接走到上台放映

判断标准：判断标准：源文件是 Markdown、现场要放映，就不用重做 PPT。

文档已经写完，讲的时候还要复制进 PPT。这次把这一步砍掉：Markdown 直接放映。

先说清楚：这是 ReadMD v2.3.7-beta.1 预览版，文件仍然保留在你自己的电脑里。

这一版的核心就一件事：ReadMD 让同一份 Markdown 从阅读、编辑直接走到上台放映。

放映界面可以直接换主题、调字号、切开场和转场；结构保护分片会尽量保住代码块、表格和公式，不让长文档在幻灯片里被腰斩。

它没有脱离原来的工作流：科研图表留在文档里、改稿时回到同屏预览。

下面的画面来自当前版本真实运行状态，不是概念图。

还有一些不适合单独拍图的底层修复也在这版里，比如顶栏交互升级与禅模式 (Zen Mode) 全局常驻；侧边「更多」菜单重构与文档状态动态联动。它们不抢画面，但会让日常使用更稳。

收藏这条判断标准：源文件是 Markdown、现场要放映，就不用重做 PPT。

渲染阶段只处理显示结果，不会替你改写原始 Markdown 文件。

如果你常处理课程讲义、组会报告、技术分享或论文汇报，它会省掉“重新做一遍演示稿”这一步。

安装包在 GitHub Releases 页面。不想翻链接的话，可以直接 GitHub 搜 Natsummerance/readMD，进仓库后点 Releases 就能找到对应平台。

你会先拿哪一份 Markdown 试放映？评论区说说场景，我会把高频路径排进下一轮打磨。

可验证证据

  • 打开文档就能看到完整排版、目录和公式渲染 — README.md, showcase/fixtures/readmd-showcase.md
  • 写完的 Markdown 能直接上台放映，代码、表格和公式不会被切片 — release/release_notes.md, assets/js/reader/render.js, evidence/release-notes.md
  • 科研图表从语法记忆变成面板选择 — assets/js/editor/editor.js, evidence/release-notes.md
  • 学术公式和定理盒子保持论文级排版 — README.md, showcase/fixtures/readmd-showcase.md, evidence/release-notes.md
  • 讲稿和源文件在同一处修改，预览不会跑偏 — assets/js/editor/editor.js, ui-tests/readmd-ui.spec.js
  • 资料进入本地工作台后，转换和阅读不散落在多个工具里 — assets/index.html
