把五个写作断点放进同一条 Markdown 工作流

很多资料不是写不完，而是在工具之间搬运时散掉了：长文档先卡住，旧文件要重打，扫描件另找服务，文献再开一个管理器，最后还要把稿子复制成幻灯片。

ReadMD 的核心边界很朴素：Markdown 是权威源文件；渲染修正只在显示层，主动保存才会写入。

五个可以单独使用的工作流

  • 长文档阅读。 接近 8,000 行或 500 KB 时启用语义分页，目录、搜索、公式和页面控件继续联动。
  • 既有文档转换。 DOCX、PPTX、XLSX、PDF、HTML 和 LaTeX 可以转入 Markdown；复杂版式仍需复核。
  • 扫描件提取文字。 Windows 使用 WinRT，macOS 使用 Apple Vision 离线识别；识别结果需要检查。
  • BibTeX 引用。 扫描同目录 .bib 文件，内联引用键显示为卡片，文末汇总被引用条目。
  • 直接放映。 Reveal 模式使用同一份 Markdown，标题、代码、公式和表格保留上下文。

适合先试的三种资料

第一种是超过几千行的研究笔记；第二种是需要整理成 Markdown 的 Word 或 PDF 报告；第三种是带 BibTeX 引用、公式和图表的课程讲义。用真实文件测试，比看功能清单更容易判断是否合适。
