写 Markdown 的人，对数据主权大多有些洁癖。我们宁可把成千上万篇笔记留在本地磁盘，也不愿随手扔给那些动不动改版、锁权限甚至下线的云端笔记软件。

ReadMD v2.3.8 刚发布，这个版本把本地优先这件事推到了一个新的完整度。

核心的改变不是堆砌新功能，而是把本地安全、多语言底座与批量管线全部收紧加固。

首先是 46 种语言的完整收尾。系统托盘、技能导入报错、图表消息、EPUB 和 LaTeX 导出设置全部完成了原生本地化。过去版本里容易回退到英文的提示，比如 41 种语言下的文本选区引导，这次全部补齐了地道的原生翻译，连带从右向左书写的语系也做好了排版对齐。

其次是图表与解压的严格沙箱化。很多工具宣称离线，背后却在偷偷加载远程脚本。ReadMD v2.3.8 彻底移除了 CSP 策略里的 unsafe-eval 漏洞，Chart.js 做到纯单机运行。针对复杂的 Vega 图表，我们专门挂载了隔离的服务端 Sidecar 沙箱，彻底掐断外链数据探针。Zip 解压逻辑也做了全盘加固，能自动拦截目录穿越、UNC 伪造和恶意 Zip 炸弹，大型二进制文件解压必须由你手动确认，绝不在磁盘里留垃圾目录。

第三是统一批量工作台。手头积攒了大量 Word、PPT、Excel 或老旧的 .doc 文档时，不需要再手动一篇篇转。新工作台支持批量导入，逐行显示耗时和输出路径。你可以随时中断任务，已经转好的文件完整保存在磁盘上，进程不会卡死。底层用纯原生 OOXML 读取器配合纯 Python OLE2 解析，电脑没装 Office 也能秒级提取纯净文本。

在开发者生态上，VS Code 扩展补齐到了 22 项原生命令，支持随时打断流式响应。配合 MCP Server，本地的大模型可以直接读取你的 Markdown 知识库，从头到尾不需要上传云端。

如果你也反感云端绑架，追求单机确定性与数据隐私，ReadMD v2.3.8 会是一个让你放心的本地主力工具。
