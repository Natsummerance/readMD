# 数学物理方法 (Mathematical Methods)

现代物理学深度依赖严格的几何与代数结构。

## 微分几何基础

外微分形式提供了无坐标的几何语言：


d(\omega \wedge \eta) = d\omega \wedge \eta + (-1)^p \omega \wedge d\eta


斯托克斯定理实现了流形边界积分的统一：


\int_{\partial M} \omega = \int_M d\omega
