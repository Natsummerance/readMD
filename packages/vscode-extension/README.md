# ReadMD for VSCode

VSCode 插件版 ReadMD —— 在 Visual Studio Code 中无缝获得 ReadMD 的清爽阅读、LaTeX PRO 增强、以及 Markdown 格式智能自动修复能力。

## ✨ 核心特性

- 📖 **智能双向预览**：与编辑器实时同步的清爽排版预览。
- 🛠️ **一键格式诊断与自愈修复**：右键菜单一键修复 Markdown 中被破坏的公式、代码块、中英文空格及错位表格。
- 📐 **LaTeX PRO 与 BibTeX 支持**：支持学术定理 Callout 与复杂多行公式。
- 🔄 **Markdown ⇄ LaTeX 互转**：一键将 Markdown 转为可编译学术 LaTeX。
