# ReadMD v2.3.8-preview.1 for macOS

## 下载

- Intel Mac：`ReadMD-macos-x64-v2.3.8-preview.1.zip`
- Apple Silicon Mac：`ReadMD-macos-arm64-v2.3.8-preview.1.zip`
- 校验清单：`SHA256SUMS.txt`

v2.3.8-preview.1 延续 @import 模块化编译、[TOC] 原生目录、TikZ/WaveDrom 科学绘图、Reveal.js 演说模式、多语言安全 Code Chunk、原生 EPUB 3.0 与 AST 双向同步能力，并包含当前候选的可靠性修复。

本候选构建面向 macOS 13+；正式支持仍需对应架构的原生安装、冷启动、签名/公证和完整功能证据。

校验方法：下载 ZIP 与 `SHA256SUMS.txt` 后运行 `shasum -a 256 ReadMD-macos-arm64-v2.3.8-preview.1.zip`（Intel 包替换文件名），再与清单同名行比较。哈希相同表示下载内容完整，不表示代码已签名或已公证。
