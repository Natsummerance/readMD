# ReadMD v2.3.1 for macOS

## 下载

- Intel Mac：`ReadMD-macos-x64-v2.3.1.zip`
- Apple Silicon Mac：`ReadMD-macos-arm64-v2.3.1.zip`
- 校验清单：`SHA256SUMS.txt`

v2.3.1 带来 46-语种完整母语化 i18n 深度审核与机翻错误全面修正、Linux 与信创国产操作系统（银河麒麟 KylinOS / 统信 UOS / 深度 Deepin / openEuler）全架构适配、HarmonyOS NEXT 鸿蒙原生应用（ArkTS + ArkWeb 实验性分包）、LaTeX PRO 学术增强、Editor Studio PRO 禅模式与智能表格、VSCode 插件与 MCP Server 多端生态。

本构建仅供 macOS 12+ 系统使用，依赖 macOS Vision 原生框架与 WebKit 原生渲染。

校验方法：下载 ZIP 与 `SHA256SUMS.txt` 后运行 `shasum -a 256 ReadMD-macos-arm64-v2.3.1.zip`（Intel 包替换文件名），再与清单同名行比较。哈希相同表示下载内容完整，不表示代码已签名。
