# ReadMD v2.3.4 for macOS

## 下载

- Intel Mac：`ReadMD-macos-x64-v2.3.4.zip`
- Apple Silicon Mac：`ReadMD-macos-arm64-v2.3.4.zip`
- 校验清单：`SHA256SUMS.txt`

v2.3.4 带来 @import 模块化编译体系、[TOC] 原生目录引擎、TikZ/WaveDrom 全景科学绘图矩阵、Reveal.js 演说模式、多语言安全 Code Chunk 执行、原生 EPUB 3.0 电子书打包与 AST 像素级双向同步。

本构建仅供 macOS 12+ 系统使用，依赖 macOS Vision 原生框架与 WebKit 原生渲染。

校验方法：下载 ZIP 与 `SHA256SUMS.txt` 后运行 `shasum -a 256 ReadMD-macos-arm64-v2.3.4.zip`（Intel 包替换文件名），再与清单同名行比较。哈希相同表示下载内容完整，不表示代码已签名。
