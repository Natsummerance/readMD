# ReadMD v2.3.2 for macOS

## 下载

- Intel Mac：`ReadMD-macos-x64-v2.3.2.zip`
- Apple Silicon Mac：`ReadMD-macos-arm64-v2.3.2.zip`
- 校验清单：`SHA256SUMS.txt`

v2.3.2 带来未保存标签页关闭确认弹窗 UI 深度重塑（毛玻璃/微米级高光边框/琥珀色柔光图标/微弹触感/无障碍键盘交互）、首页 46 国语言核心词条逐一地道化精校、全平台构建与版本同步。

本构建仅供 macOS 12+ 系统使用，依赖 macOS Vision 原生框架与 WebKit 原生渲染。

校验方法：下载 ZIP 与 `SHA256SUMS.txt` 后运行 `shasum -a 256 ReadMD-macos-arm64-v2.3.2.zip`（Intel 包替换文件名），再与清单同名行比较。哈希相同表示下载内容完整，不表示代码已签名。
