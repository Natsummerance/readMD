# ReadMD v2.3.0 for macOS

## 下载

- Intel Mac：`ReadMD-macos-x64-v2.3.0.zip`
- Apple Silicon Mac：`ReadMD-macos-arm64-v2.3.0.zip`
- 校验清单：`SHA256SUMS.txt`

v2.3.0 带来全球 45+ 语种 i18n 体系与多模型自动翻译工具链、系统语言初次启动自动识别、LaTeX PRO 学术增强与纯 Python BibTeX 文献解析、Editor Studio PRO 禅模式 / 10x10 表格设计器 / Excel 智能粘贴转 Markdown、VSCode 插件与 MCP Server 分包架构、以及软件内更新器排查与修复。

本构建仅供 macOS 12+ 系统使用，依赖 macOS Vision 原生框架与 WebKit 原生渲染。

校验方法：下载 ZIP 与 `SHA256SUMS.txt` 后运行 `shasum -a 256 ReadMD-macos-arm64-v2.3.0.zip`（Intel 包替换文件名），再与清单同名行比较。哈希相同表示下载内容完整，不表示代码已签名。
