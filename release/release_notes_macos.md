# ReadMD v2.2.8 for macOS

## 下载

- Intel Mac：`ReadMD-macos-x64-v2.2.8.zip`
- Apple Silicon Mac：`ReadMD-macos-arm64-v2.2.8.zip`
- 校验清单：`SHA256SUMS.txt`

v2.2.8 带来软件内自动检查与更新系统、LaTeX 全量环境兼容与公式自修复算法、OCR 扫描智能排版与 Markdown 规范化、欢迎页搜索禁用与 AI 助手按钮修复、以及安装程序界面去重优化。

本构建仅供 macOS 12+ 系统使用，依赖 macOS Vision 原生框架与 WebKit 原生渲染。

校验方法：下载 ZIP 与 `SHA256SUMS.txt` 后运行 `shasum -a 256 ReadMD-macos-arm64-v2.2.8.zip`（Intel 包替换文件名），再与清单同名行比较。哈希相同表示下载内容完整，不表示代码已签名。
