# ReadMD v2.2.7 for macOS

ReadMD 是免费的本地 Markdown 阅读器。

- Intel Mac：`ReadMD-macos-x64-v2.2.7.zip`
- Apple Silicon Mac：`ReadMD-macos-arm64-v2.2.7.zip`
- 完整性清单：`SHA256SUMS.txt`

v2.2.7 带来全新多标签页窗口模式（支持拖拽排序、双击内联重命名、溢出折叠与右键菜单）、全格式拖拽打开与光晕悬浮动画、剪贴板 Ctrl+V 极速建档与 Ctrl+S 保存、导出排版实时微缩预览与选项折叠、底部状态栏返回主页按钮、修复目录侧边栏收起逻辑与编辑预览方向按键。

> 两个 `.app` 均未签名。解压后首次启动请在 Finder 中右键 `ReadMD.app` →“打开”；如仍被阻止，请到“系统设置 → 隐私与安全性”确认打开。

校验方法：下载 ZIP 与 `SHA256SUMS.txt` 后运行 `shasum -a 256 ReadMD-macos-arm64-v2.2.7.zip`（Intel 包替换文件名），再与清单同名行比较。哈希相同表示下载内容完整，不表示代码已签名。
