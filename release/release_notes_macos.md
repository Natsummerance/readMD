# ReadMD v2.2.9 for macOS

## 下载

- Intel Mac：`ReadMD-macos-x64-v2.2.9.zip`
- Apple Silicon Mac：`ReadMD-macos-arm64-v2.2.9.zip`
- 校验清单：`SHA256SUMS.txt`

v2.2.9 带来全景模块化前端架构、标签页拖拽排序与折叠腾挪重命名、Markdown 索引目录智能跳转、编辑文本浮动快捷栏与撤销重做、全能剪贴板智能自适应分流建档（图文/OCR/URL/公式）、未保存标签页优雅关闭确认弹窗、主页与标签关闭状态深度清理、网页抓取现代极简双动作交互、以及轻量级 LaTeX ⇄ Markdown 双向互转引擎。


本构建仅供 macOS 12+ 系统使用，依赖 macOS Vision 原生框架与 WebKit 原生渲染。

校验方法：下载 ZIP 与 `SHA256SUMS.txt` 后运行 `shasum -a 256 ReadMD-macos-arm64-v2.2.9.zip`（Intel 包替换文件名），再与清单同名行比较。哈希相同表示下载内容完整，不表示代码已签名。
