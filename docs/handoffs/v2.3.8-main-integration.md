## 3. 已纳入的主要实现

### 后端与数据安全

- 代码运行接口要求 `confirm=true`，限制语言、超时、输出、工作目录和子进程；Unix 增加资源上限，Windows 使用进程树清理。
- EPUB 导出统一参数契约，默认写入隔离数据目录的 `exports`，处理目标冲突并要求确认。
- 样式、凭据和测试数据支持 `READMD_DATA_DIR` 隔离，避免测试污染用户目录。
- RTF、ODT、EPUB 转换返回稳定状态、引擎、输出路径、警告和错误码，移除二进制直接塞入 Markdown 的假成功路径。
- MCP 导出工具限制绝对目标路径、扩展名、父目录、覆盖权限和 `confirm=true`。
- AI HTTP 调用要求 `skill_id`，SSE 错误事件包含稳定错误码。

### 前端与网站

- Ctrl+S/保存按钮原地保存，不因成功保存退出编辑模式；同步脏状态、标签蓝点、mtime 和历史缓存。
- 长文档编辑/预览布局、选区显示、批处理和导出入口已纳入回归测试。
- 批处理入口并入“万物转 MD”流程，支持分组、取消、重试、逐项打开和安全命名。
- 网站能力影片保留 124 帧唯一素材，并改为懒加载，避免首屏预加载全部图片。
- 主题、下载页、Skill 工作台和桌宠相关 UI 改动已随候选分支合入。

### Skill、VSCode、MCP 与桌宠

- Skill 导入、来源校验、许可证/变量检查、版本快照和 GitHub/本地/ZIP 输入管线已进入候选代码。
- VSCode 扩展和 MCP 共享 Core/Skill/Provider 数据模型；MCP 已声明 tools/resources/prompts。
- Hermes 桌宠适配代码、Arch-chan 资源、来源许可证和审计文档已纳入候选树。
- 所有新增桌宠和 Skill 相关文件均保留来源、许可和风险说明；普通用户 Skill 脚本默认不执行。
