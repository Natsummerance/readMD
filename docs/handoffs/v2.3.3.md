## 优化历程与功能清单

### 1. Word ⇄ Markdown 原生 OMML 深度双向公式互转引擎
- **DOCX ➔ Markdown（万物转 MD 完美公式提取）**：
  - **全量 OMML 语法树支持**：在 `convert.py` 中扩充了矩阵与行列式 (`m:m` ➔ `\begin{matrix}`, `\begin{pmatrix}`, `\begin{bmatrix}`, `\begin{vmatrix}`)、定界符智能匹配 (`m:d` ➔ `\left( ... \right)`, `\left[ ... \right]`, `\left\{ ... \right\}`, `\left| ... \right|`)、方程组 (`m:eqArr` ➔ `\begin{aligned}` )、极限与上下界 (`m:limLow/limUpp` ➔ `\lim_{x \to 0}` )、框选 (`m:box/borderBox` ➔ `\boxed{...}`)、重音符号 (`m:acc` ➔ `\vec`, `\hat`, `\bar`, `\dot` 等)。
  - **200+ 希腊字母与数学符号映射**：内置全面的 Unicode 数学字符逆向映射表（微积分、集合论、逻辑运算、箭头、偏导、梯度等）。
  - **段落物理先后顺序流式还原**：彻底重构 `handle_para` 遍历算法，按 `w:p` 子节点先后顺序精准保留正文 Run、行内公式 `$ ... $`、超链接与独立公式块 `$$ ... $$`，终结公式脱节挤在段首/段尾的顽疾。
  - **表格单元格公式支持**：支持复杂数据表与学术表格单元格内嵌公式的完整提取。
- **Markdown ➔ DOCX（导出 Word 原生可编辑公式）**：
  - 新增轻量级 `src/readmd_modules/latex2omml.py` 编译器，将 LaTeX 数学公式直接编译为微软 Word 原生矢量 OMML 节点（`m:oMath` 与 `m:oMathPara`）。
  - 在 Word 与 WPS 中打开导出的 `.docx` 文档时，公式全部呈现为原生、矢量且支持双击编辑的微软公式对象。
- **自动化测试验证**：
  - 新增 `tests/test_omml_docx_conversion.py`，全量覆盖矩阵、定界符、根式、分数、微积分与双向转换用例，测试 100% 通过。
  - 核心转换模块与全量 self-test 验证全部通过。
