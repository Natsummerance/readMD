# ReadMD v2.2.0 设计记录

## 目标

让导出与 AI 设置在小窗口中保持可读、可滚动、可通过键盘操作；移除旧个人连接信息，并交付 Intel 与 Apple Silicon 的 macOS 包。

## 交互与视觉

- 导出设置采用“固定操作区 + 独立滚动内容区”：格式、导出动作始终可见，展开任意分组不会遮挡其他设置。
- 顶栏最近文件始终打开独立面板，不再依赖欢迎页。空记录显示明确空态，Esc、关闭按钮和点击遮罩均可退出。
- AI 连接把“官方预设”和“自定义连接”分组；模型始终是下拉选择，不提供容易出错的自由输入。
- AI 面板使用左侧蓝紫渐变调宽轨道作为唯一强化视觉元素；其余布局遵循现有设计 token、焦点环和减弱动态效果。

## 数据与发布

- AI 配置升级为 schema v2，首次读取旧格式即原子替换为无自定义连接的配置；接口只返回 Key 状态，不返回 Key 值。
- Release 由标签触发的 GitHub Actions 统一创建；Windows、macOS x64 与 macOS arm64 都必须先通过测试和归档校验。

## 验收

- 全展开展示设置时，导出弹窗仍在视口内且选项区可滚动。
- 任意阅读页面可从顶栏打开、清空并加载最近文件。
- 新建、保存、删除自定义连接以及获取模型均不泄露 API Key；模型可直接从下拉列表选择。
- Windows 回归测试与三种 CI 平台构建、测试、资产校验全部通过后才发布 `v2.2.0`。
