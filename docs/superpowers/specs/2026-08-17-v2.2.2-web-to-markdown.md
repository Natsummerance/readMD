# ReadMD v2.2.2 网页转 Markdown 设计记录

网页转换采用分层、可诊断且不捆绑 Chromium 的实现：受限 HTTP 下载 → Trafilatura 正文/高召回 → 系统 WebView 动态渲染 → Mozilla Readability → 清理后的完整页面。远程 HTML 永远不会获得 ReadMD 主窗口的 JS API，渲染窗口无持久登录态且使用后销毁。

内部接口为 `POST /api/web/extract` 与 `POST /api/web/cancel`；桌面桥接提供 `render_web_page(task_id)`。结果包含稳定错误码、元数据、抽取引擎、警告、同站候选链接和可选图片清单。旧 `/api/url` 保留兼容。

发布门要求 Windows、Intel macOS、Apple Silicon macOS 的 Python/UI 测试、冻结资源自检、架构验证和隐私扫描全部通过，由一个 Release job 发布四个 v2.2.2 资产。
