# 万物转MD与打开文件：逐格式后端矩阵

[返回总清单](../readmd-ui-function-inventory-2026-10-02.md)

目录收集枚举去重后107种后缀；本表143行，另含直接分派/Markdown/图片/明确拒绝项。后缀比较采用小写，枚举重复项不重复统计。收集能力：[rust/readmd-kernel/src/convert.rs:230](../../../rust/readmd-kernel/src/convert.rs)；实际分派：[rust/readmd-kernel/src/convert.rs:353 · convert_triple](../../../rust/readmd-kernel/src/convert.rs)；Win7精简枚举由兼容配置/READMD_FORCE_WIN7路径影响，不能把该枚举当作本次在Win7系统实测。

操作入口：万物转MD → 文件/文件夹 → 覆盖策略 → 自动加入任务 → 进度/取消 → 点结果打开/打开目录。批量文档经batch2::h_convert_batch；图片另走OCR；拖ZIP先拆包。单文件的skip/overwrite/rename和批处理覆盖勾选分别记录在主体文档。输出通常是同名.md及需要的图片资源，实际out/saved/skipped/warning以响应为准。
