# ReadMD V2.3.8 Live2D desktop-pet manual review

Candidate scope: `codex/v2.3.8-reliability` after commit `7b7c606` plus the
uncommitted Live2D readiness slice. This is a review protocol, not evidence
that a model, Cubism licence, or platform implementation is already approved.

## What is implemented for review

- A default-off, renderer-independent pet state machine. It limits activity to
  30fps, idles at 6fps, freezes under reduced-motion, and hides while a
  fullscreen application is active.
- A non-destructive batch queue. Markdown, image, conversion, and unsupported
  inputs are separated; a task cannot report the original path as its output.
- A fail-closed original-model manifest verifier. It validates a complete
  rights chain, per-file SHA-256 values, ordinary files only, and containment
  inside `assets/pet/model/`.
- An explicit pywebview native-window capability probe. It uses a transparent,
  frameless, on-top window, but does not claim click-through, WebGL, drag/drop,
  or multi-display support without a human test.

No Cubism SDK/Core, Live2D model, third-party art, Hermes/Petdex asset, browser
fallback, or substitute sprite animation is in this candidate.

## Reviewer prerequisites

1. Use a throwaway document and a non-production display configuration.
2. Confirm the candidate is on this branch and execute:

   ```powershell
   python -m pytest -q tests/test_pet_runtime.py tests/test_pet_api_contract.py
   python -m src.readmd_modules.pet.probe
   ```

3. The first command must pass. The second command prints a JSON capability
   report and opens one small circular probe window. Closing it exits the probe.
   It does not install or activate a pet in ReadMD.

## Windows 10/11 native-window checklist

Record the Windows edition/build, GPU driver, scale factor, monitor count,
pywebview version and candidate commit alongside each result.

| Check | Expected result | Result / evidence |
|---|---|---|
| Native window | Probe opens as its own WebView2 window, not a browser tab | |
| Transparency | Only the circular surface is visible; rectangular background is transparent | |
| On-top | Probe remains above ReadMD, then returns normally after closing | |
| Drag | Probe can be moved without moving or blocking ReadMD | |
| Fullscreen policy | Open a fullscreen app; future controller is expected to hide pet | |
| Reduced motion | State report gives `animation_enabled:false` and `fps_cap:0` | |
| Multi-display | Move between DPI-scaled displays; position, transparency and drag remain stable | |
| Click-through | Verify separately; pywebview capability report deliberately remains `manual-verification-required` | |
| Drag/drop | Verify separately after renderer adapter exists; current probe makes no claim | |

Any blank, failed, browser-fallback, or visually degraded row blocks a claim of
Windows native Live2D support.

## Required material and licence sign-off before a renderer can be added

The rights holder must add an original bundle to `assets/pet/model/` with
`readmd.live2d.json` and run its hash verification. The record must identify:

- original layered art and Cubism project/source custody;
- author or commission agreement and redistribution permission;
- exact model/motion/physics asset file hashes;
- Cubism SDK/Core version plus the applicable written publication licence;
- NOTICE/SBOM entries and the intended Windows, macOS and Linux release forms.

Live2D’s current terms say that publication using the SDK requires the relevant
release licence; applications with significant expandability require a separate
review and agreement. ReadMD’s future user-importable model/Skill ecosystem may
fall into that review path, so this cannot be inferred from a free development
download. See [SDK Release License](https://www.live2d.com/en/sdk/license/) and
[Expandable Applications](https://www.live2d.com/en/sdk/license/expandable/).

## Explicit non-approval

- Windows: only this probe is ready for human review; no real model, click-through
  or batch drag/drop evidence exists.
- macOS/Linux: no native runtime session has been performed for this candidate.
- Release: blocked until licence, original model, per-platform native results,
  renderer dependency inventory, NOTICE/SBOM, and automated regression evidence
  are complete.
