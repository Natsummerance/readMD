# 文档转换与导出升级

本轮仅处理文档导入与 Markdown 导出，已接入现有转换入口及导出面板。

## 导入

- Word：保留 DOCX 内容控件、已接受视图的修订文字与嵌入图片；修复 DOC 转换后图片随临时目录清理而丢失。
- PDF：按明显的双栏间隙调整阅读顺序，保留文字页中的图片；逐页尝试 OCR，无法识别时保留扫描页图片并说明原因。
- PowerPoint：PPTX 支持组合形状中的内容、图片、表格、缓存图表数据、备注及基础文字格式。
- EPUB：按阅读脊柱顺序解析，保留标题、表格、链接与图片；图片存入源文件旁的 `.assets` 目录。

## 导出与版式

- 新增 A3、自定义纸张尺寸、首行缩进、页眉、图片宽高限制、章节分页；保留原有页边距、字号、行距、配色等设置。
- PDF：自定义纸张真实生效，长表格自动换行并跨页，长代码块可分页，图片等比例缩放，标题与后文保持相邻。
- DOCX：原生目录字段、页眉、手动分页、重复表头、单元格内边距和所选字体。
- HTML：修复离线渲染资源定位，嵌入本地图片，统一字号单位，支持打印版式和显式分页。
- EPUB：使用结构化 XHTML 保留表格、代码、引用、链接和图片，并将图片打包入书内；代码块内的标题不再错误分章。
- 可在 Markdown 中使用 `<!-- pagebreak -->`、`<!-- page-break -->` 或独立一行的 `\newpage` 分页。
- Windows 打包配置补充 PPTX、HTML 解析器相关依赖收集。

## 验证

相关自动化测试 **140 项通过**，包含新增的 8 项真实文件生成与内容校验，覆盖 Word 内容控件/图片、PPTX 图表/备注、EPUB 阅读顺序、双栏与扫描 PDF、导出纸张尺寸、长代码/长表格及便携图片资源。前端脚本语法检查通过。

`build/document-upgrade-samples/` 中已生成 `sample.md`、`sample.pdf`、`sample.docx`、`sample.html`、`sample.epub` 和 `verification.json`。四种导出均成功且无警告；PDF 为 3 页，中文尾部内容可提取；HTML 在无界面浏览器中验证图片、表格、公式和分页标记正常，无 JavaScript 错误。未进行截图或人工视觉验收，未构建发布安装包。

## 能力边界

Markdown 无法等价表达任意浮动排版、复杂合并单元格或动画；本轮提升内容保留与基础结构，不承诺像素级还原。双栏识别采用保守启发式。扫描文字识别依赖可用 OCR 引擎；原始 DOC/PPT 等旧格式仍依赖原有转换引擎。Word 目录字段可能需要在 Word/WPS 中刷新；EPUB 的最终分页取决于阅读器，数学公式以 LaTeX 文本保留。远程图片仍不自动下载。
