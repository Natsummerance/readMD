# v2.2.5 Markdown / LaTeX 往返调研（仅调研）

状态：提案；本文件**不**新增入口、Python 依赖、打包资源或运行时行为。目标是为下一版建立能执行、可验证的 Markdown ⇄ LaTeX 工作流，而不是承诺“所有 LaTeX 无损”。

## 目标与非目标

目标是把 ReadMD 中用户明确选择的 Markdown 文档导出为可编译的 LaTeX，并可把受支持的 LaTeX 子集导回结构等价的 Markdown。公式需保留为 TeX；表格、链接、图片、代码、引用、脚注和标题层级要有稳定映射。导出应离线、可重复、不会覆盖原始 Markdown。

非目标：实现 TeX 引擎、解释任意宏包、执行 shell escape、下载远程图片/包、或把任意 `.tex` 源码逐字节还原。PDF 编译可以是用户自备工具链的后续可选步骤，不属于首个转换器。

## 方案比较

| 方案 | 优点 | 风险 / 成本 | 结论 |
| --- | --- | --- | --- |
| Pandoc CLI | Markdown、LaTeX 与引用生态成熟；AST 可表达复杂结构；模板和 filters 成熟 | 外部可执行文件分发大；不同 Pandoc 版本输出可能变化；需严控参数与临时文件 | **推荐核心**：固定版本的 CLI + JSON AST 边界 |
| pypandoc | Python 调用方便，能定位/下载 Pandoc | 本质仍依赖 CLI；自动下载不适合离线桌面程序；版本来源与错误处理容易变模糊 | 不作为产品依赖；可留给开发工具脚本 |
| 纯 Python Markdown AST | 小体积、易嵌入、可完全离线 | 很难覆盖 LaTeX parser、宏、表格、引用与原样块；多个 Markdown parser 的 AST 不兼容 | 仅可用于输入预检查 / 小范围后处理 |
| 自研 Markdown↔LaTeX parser | 控制最高、可专门优化 ReadMD | 维护成本极高；兼容性与安全边界难以长期保证 | 不建议作为 v2.2.5 路线 |

## 推荐架构：固定 Pandoc AST 边界

1. 用户从未来的“导出 LaTeX / 导入 LaTeX”明确发起操作；读取文件后仍走现有编码与路径校验。
2. 以固定、经校验的 Pandoc 版本运行 `pandoc --from ... --to json`，把 JSON AST 作为唯一的结构边界；不要把任意 TeX 直接拼接进模板。
3. `md → tex`：Markdown AST 先经过 ReadMD 的纯函数规范化（例如图片相对路径、受支持的属性），再交给 Pandoc writer 或受限 Lua filter 输出 `.tex`；模板由随包资源提供。
4. `tex → md`：只接受明确的 reader 格式与资源根目录，先由 Pandoc 生成 JSON AST，再以统一 writer 生成 GFM/CommonMark 风格 Markdown；报告所有降级项。
5. 每次转换生成 `ConversionReport`（输入格式、Pandoc 版本、资源结果、警告、不可逆项），但不记录全文或用户路径到日志。

固定 AST 让产品代码能对节点白名单、资源和降级策略做测试；Pandoc 只负责语言兼容层。首版不要让 Lua filter 执行任意用户脚本，也不要开启 `--shell-escape`。

## 固定样例与计划项

`fixtures/latex-roundtrip/reference.md`（未来新增，当前不创建）必须覆盖下列所有计划项；每项有预期 Markdown、预期 AST 片段和预期 `.tex` 片段。

| 计划项 | 固定样例 | md → tex | tex → md / 预期 |
| --- | --- | --- | --- |
| 标题、段落、强调、删除线 | `# 标题`、`**粗体**`、`*斜体*`、`~~删~~` | `\section` / `\textbf` / `\emph` / `\sout`（由模板提供） | 结构等价；模板所需宏列入前言 |
| 链接、自动链接、图片 alt/title | 相对图片、含空格路径、https 链接 | `\href` / `\includegraphics`，资源经复制或保留相对引用 | 图片缺失为警告，不读取网络 |
| 有序/无序/任务列表 | 嵌套 3 层、任务勾选 | `enumerate` / `itemize`，任务以受控宏渲染 | 任务状态保留；未知列表属性降级为文本 |
| 引用、分隔线、代码 | 多段引用、语言代码围栏、反引号 | `quote` / `\hrule` / `Verbatim` | 代码字节内容保持；语言提示可降级 |
| 表格 | 对齐列、转义竖线、空单元格 | `longtable` 或模板选定表格环境 | 规则表格往返；合并单元格明确为不支持 |
| 行内/块级公式 | `$E=mc^2$`、`$$\\int_0^1 x dx$$` | 原样 TeX math | 公式主体保留；不能解析的 TeX 标为 raw-math 警告 |
| 脚注、引用键 | `[^1]`、`[@doe2024]` | footnote；citation 需用户提供 bibliography | 无 bibliography 时保留 citation 文本并警告 |
| YAML 元数据 | title/author/date/lang | 映射到模板变量，值转义 | 已知字段保持，复杂对象作为 YAML 保留或警告 |
| HTML 与属性 | `<span>`、`{#id .class}` | 仅白名单语义属性；其余不执行 | 不能等价的 raw HTML 降级为 fenced/raw block |
| LaTeX 环境/宏 | `\begin{theorem}`、自定义 `\foo` | 不从 Markdown 生成任意用户宏 | 导入时保留为 raw TeX block + “不可无损”警告 |
| 图表/嵌入 | Mermaid、iframe、远程媒体 | 不执行、不下载；可渲染为代码或链接 | 明确降级，报告中列出 |

每个 fixture 都执行四项断言：转换进程退出为零、输出没有意外绝对路径、标准化后的 AST 与 golden JSON 一致、输出再解析后满足定义的结构不变量。golden 文件由固定 Pandoc 版本生成；升级 Pandoc 时必须人工审阅差异。

## 依赖与分发

- 首选把经许可审查的 Pandoc 二进制按 Windows x64、macOS x64、macOS arm64 分别随应用资源分发，记录准确版本、上游许可证和 SHA-256 到第三方声明；不在首次使用时下载。
- 二进制通过应用资源路径定位，不能从文档目录、`PATH` 或环境变量接收可执行文件；调用使用参数数组、固定工作目录、超时和最小环境变量。
- 若为控制体积而不内嵌，UI 必须显示“未安装转换器”，给出用户选择的受信任路径与版本/哈希展示；不能静默联网安装，不能回退到任意 `pandoc`。
- 模板、Lua filter（若采用）和默认 bibliography 样例均为只读打包资源。用户模板需要后续单独设计，默认不支持可执行 hooks。
- 依赖故障、版本不匹配、超过大小/时限、无可写临时目录时，保留原文并返回可操作的本地错误；绝不把内容上传到服务端。

## API 草案

以下是纯内部 API 草案，不是 v2.2.4 的实现承诺：

```python
@dataclass
class LatexOptions:
    resource_root: str
    copy_resources: bool = False
    bibliography: str | None = None
    template: str = "readmd-default"

@dataclass
class ConversionReport:
    ok: bool
    warnings: list[str]
    unsupported: list[str]
    resources: list[dict[str, str]]
    pandoc_version: str

def markdown_to_latex(text: str, options: LatexOptions) -> tuple[str, ConversionReport]: ...
def latex_to_markdown(text: str, options: LatexOptions) -> tuple[str, ConversionReport]: ...
def inspect_pandoc() -> dict[str, str | bool]: ...
```

UI 层只消费文本、用户选择的输出路径和报告摘要。资源复制采用“先写同目录临时目录、完成后原子替换”；资源名必须规范化，拒绝绝对路径、`..`、符号链接逃逸和 URL。默认最多 10 MB 源文本、100 个资源、单资源 25 MB、总资源 200 MB、单次进程 30 秒；这些数值应成为可测的常量，而不是隐藏配置。

## 资源与降级规则

| 条件 | 行为 |
| --- | --- |
| 本地相对图片存在且在资源根目录内 | 可复制到输出 `assets/`，报告记录相对映射 |
| 图片不存在、越界、是 URL 或超过限制 | 输出保守占位/链接，报告警告；不联网 |
| 不认识的 LaTeX 环境、宏、TikZ、minted | 保留 raw TeX fenced block 或注释，报告 `unsupported` |
| Pandoc 不可用 / 版本不符 | 不生成半成品；显示安装/修复说明 |
| TeX 编译失败 | 若未来提供编译，仅保留 `.tex` 与 stderr 摘要；不删除用户输出 |
| 引用库或 CSL 缺失 | 不执行引用渲染；保留 citation key 并警告 |

“降级”必须可见、可复制和可保存到报告，不能悄悄丢失内容。任何 raw TeX 都不在 ReadMD 预览中执行。

## 往返语料与验收

语料分为：`commonmark/`（基础块/行内）、`gfm/`（表格、任务、删除线）、`math/`、`resources/`、`metadata/`、`latex-import/`、`adversarial/`（巨大表格、深嵌套、恶意路径、zip bomb、控制字符、未知宏）。每组至少包含 ASCII、中文、emoji、RTL 文本、CRLF/LF 和包含空格/Unicode 的资源名。

往返比较采用 AST 规范化而非文本逐字比较：忽略安全的空白、writer 选择的列表编号和必要的模板格式；保留文档结构、可见文字、链接目标、公式主体、任务状态、表格单元格与资源映射。无法做到 AST 等价的 fixture 必须在 golden report 中列出降级原因。

## 无法无损的边界

LaTeX 是可编程排版语言，宏定义、条件、类别码、外部包、TikZ、`\\write18`、动态引用和任意 raw TeX 都不能从 Markdown 可靠地反推，也不应执行。Markdown 的原始 HTML、复杂表格、嵌入式网页和样式属性同样没有通用 LaTeX 等价物。因此产品文案只能承诺“受支持子集的结构化转换与可见降级报告”，不能承诺任意 `.tex`、任意 PDF 或任意 Markdown 无损往返。

## 落地顺序

1. 固定 Pandoc 版本、许可证清单和三平台资源定位 POC；验证无网络、超时和错误报告。
2. 建立上述 fixture、golden AST/report 与 CI 版本锁定。
3. 实现纯转换服务和资源复制，先不加 UI 入口。
4. 通过安全评审后，再设计可见的导入/导出 UI、报告和用户模板边界。
5. 仅在三平台 Bundle、降级语料和 roundtrip 门禁通过后考虑发布。
