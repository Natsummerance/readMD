# BongoCat

ReadMD adapts Windows Raw Input decoding and physical key mapping from
[ayangweb/BongoCat](https://github.com/ayangweb/BongoCat), revision
`e5922f3c71716ba06531324f4ab5f8066b2cc487`, under Apache-2.0.

The upstream license and precise adaptation boundaries are preserved in
`third_party/bongocat/LICENSE` and `third_party/bongocat/UPSTREAM.md` and bundled
in the native pet runtime's `licenses/bongocat/` directory. The adaptation uses
ReadMD's existing dependencies. The classic desktop cat uses the upstream
standard model, keyboard, mouse and key overlays, with the original files
preserved under `packages/readmd-pet-rust/models/bongocat-standard/`.
MMmmmoko's Bongo-Cat-Mver is credited by the upstream project. The existing
ReadMD Cubism runtime is reused; no upstream SDK binaries are included.
