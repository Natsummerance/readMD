# Arch-chan Live2D model notice

ReadMD includes the runtime model files selected for manual evaluation from
[`Speykious/arch-chan`](https://github.com/Speykious/arch-chan), revision
`ed43dcf7e88d56f79d2e42fecb084bf6923f44e0`. The upstream repository describes
the Arch-chan Live2D model as CC0 1.0 Universal and ships its full CC0 text;
ReadMD preserves that text as
`assets/pet/model/ARCH-CHAN-CC0-1.0.txt`.

This notice applies only to the model assets. Live2D Cubism Core and SDK
components have their own terms and are deliberately not bundled. Until their
publication/use conditions are recorded and the native window passes manual
evidence, ReadMD keeps the desktop pet disabled by default.
