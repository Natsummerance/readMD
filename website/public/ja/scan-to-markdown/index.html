スキャン文字を編集可能な Markdown へ。

Windows と macOS では、ReadMD が OS の native 認識エンジンをローカルで呼び出します。スキャンは装置に残り、結果は確認してから保存できます。

ローカル OCR ワークフロー

  1. スキャンを準備

    ローカルにある鮮明な画像か PDF 頁を使います。まっすぐで読みやすい文字ほど結果が整いやすくなります。

  2. 追加または貼り付け

    ReadMD にスキャンを追加するか、クリップボード workflow で貼り付けたスクリーンショットから文字を抽出します。

  3. ローカルで認識

    Windows は WinRT OCR、macOS は Apple Vision のオフライン認識を使います。これらの経路にクラウド アカウントは不要です。

  4. 確認して保存

    読書順、見出し、表、キャプション、固有名詞、数値を直してから Markdown を保存または編集します。

OCR の質問

どの環境がオフライン OCR に対応しますか？

ReadMD は Windows では WinRT、macOS では Apple Vision によりローカルのオフライン認識に対応します。実際の可用性は OS と装置の能力に依存します。

スクリーンショットから文字を抽出できますか？

対応環境ではできます。ReadMD にはクリップボード workflow があり、貼り付けたスクリーンショットの文字を Web サービスへ送らずに抽出できます。

OCR は表やレイアウトを完全に保ちますか？

保ちません。認識品質は鮮明さ、言語、書体、レイアウトの複雑さに依存します。抽出後に見出し、表、数値、固有名詞、読書順を確認してください。

認識のためにスキャン頁はアップロードされますか？

されません。限定した Windows と macOS の OCR 経路はローカル実行を前提にし、クラウド アカウントを要求しません。
