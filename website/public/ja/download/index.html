ReadMD MCP Server · ワンクリック即時導入

Claude Desktop、Cursor、Antigravity、VS Code にローカル Markdown 自動修復、学術 LaTeX 相互変換、Office/PDF 抽出機能を提供します。

MCP パッケージをダウンロード (.zip) GitHub ソース
1 ダウンロードと解凍

上の readmd-mcp-server.zip をダウンロードし、任意のフォルダ（例: ~/readmd-mcp）に展開します。

2 設定 JSON をコピー

ご利用の AI クライアント（Claude / Cursor / Antigravity）を選択し、「設定 JSON をコピー」をクリックします。

3 再起動して即時利用

AI アプリを再起動すると、Markdown 修復や LaTeX 変換が自動的に利用可能になります。

設定ファイルパス: macOS ~/Library/Application Support/Claude/claude_desktop_config.json | Windows %APPDATA%\Claude\claude_desktop_config.json 
{
  "mcpServers": {
    "readmd": {
      "command": "python",
      "args": ["/path/to/readmd/packages/mcp-server/readmd_mcp_server.py"]
    }
  }
}

オープンソース版のシステム信頼とインストール案内

ReadMD のすべてのリリースは GitHub Actions CI で自動ビルドされています。コミュニティ版は商用署名がないため、初回起動時に OS の警告が表示される場合があります：

  • Windows: Microsoft Defender SmartScreen が表示された場合は「詳細情報」をクリックし「実行」を選択してください。
  • macOS: Gatekeeper でブロックされた場合はアプリアイコンを右クリックして「開く」を選択するか、ターミナルで xattr -d com.apple.quarantine ReadMD.app を実行してください。
  • Linux: AppImage を実行する前にターミナルで chmod +x ReadMD-linux-*.AppImage を実行して実行権限を付与してください。
