オープンソースパッケージの信頼とインストール

ReadMD の全ビルドは GitHub Actions 公開 CI で透明性をもって構築されています。コミュニティビルドのため初回起動時にセキュリティ警告が表示される場合があります：

  • Windows: Microsoft Defender SmartScreen が表示されたら「詳細情報」→「実行」をクリックしてください。
  • macOS: Gatekeeper でブロックされた場合、アプリアイコンを右クリックして「開く」を選択するか、ターミナルで xattr -d com.apple.quarantine ReadMD.app を実行してください。
  • Linux: AppImage の実行前にターミナルで chmod +x ReadMD-linux-*.AppImage を実行してください。
