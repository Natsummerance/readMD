ReadMD v2.3.7 の変更点。

このベータでは発表の分離と更新整合性を強化し、起動時の資産読み込みとタブ反応を改善します。Markdownは引き続き正となるファイルです。

リリースの要点と境界

  1. より安全な発表経路

    アプリ内 Reveal.js は同一オリジンのオフライン資産だけを読み込み、スライド HTML は許可リストで消毒されます。

  2. 整合性を優先する更新

    公式资产は固定ディレクトリへダウンロードし、SHA-256 を通してから原子的に公開し、実行前に再検証します。

  3. 軽い対話読み込み

    入口スクリプトを段階的に読み込み、共有資産は必要時に読み込み、ETag 再検証に対応し、検索 Enter はフォーカスを保ちます。

  4. 明確なタブ状態

    選択と ARIA 状態を即時更新し、古い描画結果を破棄し、あふれた場合は活動タブへスクロールし、Zen モードの Escape 経路を統一します。

V2.3.7 リリース候補のよくある質問

v2.3.7 は正式版ですか？

いいえ。ベータです。テストとフィードバックに適しますが、インストール前にバックアップと SHA-256 検証を行ってください。

表示修復は Markdown を書き換えますか？

いいえ。描画修復はメモリー上の表示層だけです。明示的に編集して保存したときだけソースバイトが変わります。

更新はどう検証しますか？

更新は公式 GitHub Release 資産から固定ディレクトリの一時ファイルへ入り、SHA-256 検証後に原子的に公開され、実行前にも再検証します。

どのプラットフォームにパッケージがありますか？

候補は Windows、Intel/Apple Silicon macOS、Linux x86_64/ARM64、UOS、Kylin、Deepin を対象とします。各環境のネイティブ証拠が揃うまで正式提供を確定しません。HarmonyOS/OpenHarmony は v2.3.7 の対象外です。
