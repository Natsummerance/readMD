ReadMD v2.3.8 の変更点。

ReadMD v2.3.8 はセルフユースチャネル初の正式版です。バッチ変換を中止可能な統合ワークベンチにまとめ、PPTX と XLSX をネイティブ解析に切り替え、チャートとアーカイブ処理を安全に強化し、46 言語の UI を仕上げました。

リリースの要点と境界

  1. ひとつのバッチワークベンチ

    変換、OCR、書き出しのタスクを統合ワークベンチに集約。どのタスクも中止でき、結果は行単位で追跡できます。

  2. ネイティブ OOXML 解析

    PPTX と XLSX はファイル形式を直接読み取ります。旧 Office 形式は曖昧なエラーではなく明確なメッセージを表示します。

  3. チャートとアーカイブの強化

    zip 展開はパス操作や zip 爆弾を拒否し、Vega/Vega-Lite は unsafe-eval を使わないサーバーサイド サンドボックスで描画します。PlantUML はリモート描画前に確認、Chart.js はオフライン描画に対応します。

  4. 46 言語と安定した拡張

    システムトレイからスキル導入までの表示文言を 46 言語に整備。VS Code と MCP は動的スキル、ストリーミング中止、接続状態表示に対応し、スキル導入は失敗時に自動ロールバックします。

v2.3.8 正式版のよくある質問

v2.3.8 は正式版ですか？

はい。v2.3.8 は 2026-09-03 に GitHub で正式リリース（プレリリースではありません）として公開されました。READMD_SELF_USE_RELEASE セルフユースチャネル経由の提供のため資産は未署名で、ネイティブ プラットフォーム証拠の一覧は参考情報です。インストール前にバックアップを取り、SHA256SUMS.txt を確認してください。

表示修復は Markdown を書き換えますか？

いいえ。描画修復はメモリー上の表示層だけです。明示的に編集して保存したときだけソースバイトが変わります。

更新はどう検証しますか？

更新は公式 GitHub Release 資産から固定ディレクトリの一時ファイルへ入り、SHA-256 検証後に原子的に公開され、実行前にも再検証します。

どのプラットフォームにパッケージがありますか？

正式版のパッケージは Windows 10/11（x64/ARM64）、macOS 13+（Intel と Apple Silicon）、Ubuntu 22.04/24.04 と Debian 12 の Linux x86_64/ARM64 を対象とします。UOS、Kylin、Deepin はネイティブ証拠が未整備のため正式サポートの約束ではありません。HarmonyOS/OpenHarmony は v2.3.8 の対象外です。
