ReadMD v2.3.9 の変更点。

ReadMD v2.3.9 はセルフユースチャネル経由で公開された正式版です。CC0 許諾の Arch-Chan Live2D デスクトップ伴読ペットを導入し、ネイティブベクター PDF エディターと FastMCP ツールチェーンを追加し、純粋 Python による Word .doc と複雑な表のクラスタリング再構築を強化し、カーネル安全監査を実施し、UI の絵文字排除と 46 言語の完全整合を完了しました。

リリースの要点と境界

  1. Live2D デスクトップ伴読ペット

    CC0 許諾の Arch-Chan Live2D モデルを統合。高 DPI Retina スケーリング、双方向ウォッチドッグ、ヒットテスト、ドラッグ＆ドロップでの即時閲覧、46 言語の吹き出し対話に対応します。

  2. ネイティブベクター PDF と MCP ツール

    高品位なテキスト修復を行うネイティブベクター PDF 編集エンジンを内蔵し、外部 Agent 連携のための ReadMD MCP Server ツールを拡充しました。

  3. オフライン Word と複雑な表

    COM 依存を排除した純粋 Python による Word .doc バイナリ（FIB/CLX）解析と、複数行・複数列にまたがる表を正確に復元するクラスタリング技術を導入しました。

  4. カーネルサンドボックス強化とクリーンな UI

    64 ビット Windows Job Object、POSIX セレクターの残り時間待機、SQL サンドボックス隔離を導入し、UI のハードコード絵文字をベクター SVG に置換し、46 言語辞書を完全整合しました。

v2.3.9 正式版のよくある質問

v2.3.9 は正式版ですか？

はい。v2.3.9 は 2026-09-10 に GitHub で正式リリース（プレリリースではありません）として公開されました。READMD_SELF_USE_RELEASE セルフユースチャネル経由の提供のため資産は未署名で、ネイティブ プラットフォーム証拠の一覧は参考情報です。インストール前にバックアップを取り、SHA256SUMS.txt を確認してください。

表示修復は Markdown を書き換えますか？

いいえ。描画修復はメモリー上の表示層だけです。明示的に編集して保存したときだけソースバイトが変わります。

更新はどう検証しますか？

更新は公式 GitHub Release 資産から固定ディレクトリの一時ファイルへ入り、SHA-256 検証後に原子的に公開され、実行前にも再検証します。

どのプラットフォームにパッケージがありますか？

正式版のパッケージは Windows 10/11（x64/ARM64）、macOS 13+（Intel と Apple Silicon）、Ubuntu 22.04/24.04 と Debian 12 の Linux x86_64/ARM64 を対象とします。UOS、Kylin、Deepin はネイティブ証拠が未整備のため正式サポートの約束ではありません。HarmonyOS/OpenHarmony は v2.3.9 の対象外です。
