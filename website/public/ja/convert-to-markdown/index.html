ホーム / ワークフロー / Markdown 変換

既存文書を Markdown へ移します。

報告書、スライド、表計算、論文、Web ページ、スキャン頁をブラウザー アップロードなしで編集可能な Markdown にできます。

ローカル変換ワークフロー

  1. ソースを準備

    DOCX、PPTX、XLSX、PDF、HTML、LaTeX のファイルをローカルに置きます。

  2. 読み込む

    一つの文書、複数ファイル、対応フォルダーを追加します。一括処理ではドラッグ アンド ドロップを使えます。

  3. Markdown へ変換

    変換を実行し、生成された Markdown を元の資料と並べて確認します。

  4. 構造を確認

    公開や追記の前に、見出し、リスト、表、数式、画像参照、OCR 結果を確認します。

変換に関する質問

どの形式を Markdown に変換できますか？

ReadMD は DOCX、PPTX、XLSX、PDF、HTML、LaTeX を Markdown へ変換します。Web ページ取得は任意機能であり、利用者が要求したときだけ通信します。

DOCX や PDF はオフラインで変換できますか？

対応環境ではできます。ローカル ファイル変換にクラウド アカウントは不要で、Web フォームへのアップロードも必要ありません。

どの文書構造が保たれますか？

見出し、リスト、表、引用、数式、画像参照など有用な Markdown 構造を保ち、不要な専用ラッパーを取り除くことを目指します。

変換後のレイアウトは完全に同じになりますか？

なりません。専用レイアウトに一対一の Markdown 表現があるとは限りません。特に複雑な設計では、見出し、表、数式、画像を変換後に確認してください。
