ホーム / ワークフロー / PDF から Markdown

PDF を編集可能な Markdown に。

テキスト型の報告書、論文、マニュアル、スキャン頁をローカルで Markdown に移行できます。元ファイルは端末に残り、再利用できる構造はできる範囲で保持されます。

ローカル PDF 変換ワークフロー

  1. PDF を端末に置く

    元の PDF を端末に置き、テキスト型かスキャン型かを判断します。

  2. ファイルを読み込む

    PDF を ReadMD に追加します。同じ確認が必要な資料はまとめて処理できます。

  3. Markdown に変換

    変換を実行し、結果を元の PDF のそばで開きます。

  4. 保存前に確認

    見出し、リスト、表、読み順、数式、キャプション、画像参照を確認してから編集や公開に進みます。

PDF 変換のよくある質問

どの PDF を変換できますか？

ReadMD の変換機能は PDF を受け付けます。テキスト型は Markdown へ対応しやすく、スキャン頁は対応環境でローカル OCR ワークフローを使います。

PDF のアップロードは発生しますか？

いいえ。ローカル PDF 変換はクラウドアカウントやブラウザフォームなしで動くように設計されています。

どの Markdown 構造が保たれますか？

PDF から復元できる場合、見出し、リスト、表、引用、数式、画像参照をできる範囲で保持します。

すべてのスキャン PDF が完璧になりますか？

なりません。OCR の品質は明瞭さ、言語、フォント、レイアウトに依存します。固有名詞、数値、表、キャプション、読み順を保存前に確認してください。
