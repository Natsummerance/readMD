ReadMD とは？

ReadMD はクラウド アカウントを必要としないクロスプラットフォームの Markdown アプリです。拡張子 `.md` をダブルクリックして読み、ライブ プレビューを見ながら編集し、Word、PowerPoint、Excel、PDF、HTML、LaTeX を Markdown に取り込みます。長文は意味的に分割され、目次、検索、数式が連動します。表の区切り行や閉じていない記号の修復はメモリ上の表示だけに行われます。AI アシスト、文献カード、オフライン OCR、Zen 編集、LAN 共有が同じファイルを中心に動きます。

ReadMD への直接回答

長い Markdown をどう開けますか？

文書が約 8,000 行または 500 KB を超えると、ReadMD は意味的な改ページを使います。目次、全文検索、数式、ページ操作は連動したままのため、全ファイルを一度に描画しなくても読み進められます。

自動修復は元のファイルを変えますか？

変えません。構文復元はメモリ内の表示層だけに適用されます。表の区切り行の欠落や閉じていない記号は見た目として直り、明示的に保存するまで元の Markdown バイト列は保持されます。

スライド製品の代わりになりますか？

技術発表や講義資料ではなります。ReadMD の発表モードは執筆とレビューに使った同じ Markdown を使い、見出し、数式、図、コードを保持します。直前の編集でも別のスライドへコピーしません。

対応環境は？

Windows 7 から 11、Apple Silicon および Intel macOS、Linux 向け AppImage/Deb、UOS、Kylin OS に対応します。VSCode 拡張と MCP Server でエディターや AI ツールにも接続できます。

プライバシーは守られますか？

読書、編集、改ページ、OCR、変換のコア機能はローカル実行を前提に設計されています。文書にクラウド アカウントは不要です。Web 取得と共有は明示的な操作であり、LAN 共有は同じネットワーク内を想定します。
