長い Markdown を固めずに開けます。

ReadMD は表示層だけを分割し、Markdown ソースを正として扱います。目次、検索、数式、ページ操作を保ったまま読み進められます。

ローカル読書ワークフロー

  1. 文書を開く

    Markdown をダブルクリックするか、ReadMD で選びます。読書は常にローカルのソースから始まります。

  2. 改ページに任せる

    約 8,000 行または 500 KB 近辺で意味的な改ページが働き、全ノードの描画を待ちません。

  3. 文脈を保って移動する

    章の間を移動しても、目次、全文検索、数式、ページ操作は接続されたままです。

  4. 修復は表示まで

    表の区切り行や壊れた強調は表示層で整えられます。明示的に編集して保存したときだけ元ファイルが変わります。

最初に聞かれる質問

どのくらいの Markdown が長文ですか？

ReadMD では約 8,000 行または 500 KB 近辺で意味的な改ページが関係します。正確な位置は文書構造や装置環境により変わります。

改ページは元の Markdown を変えますか？

変えません。改ページは表示方法だけを変えます。利用者が明示的に編集して保存しない限り、元のバイト列は保持されます。

長文でも検索や移動できますか？

できます。表示が分割されても、目次、全文検索、数式描画、ページ操作は連動します。

読むときに文書はアップロードされますか？

されません。読書、改ページ、表示修復のコア機能はローカル実行を前提にし、クラウド アカウントを要求しません。
