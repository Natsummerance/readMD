ホーム / ワークフロー / BibTeX 引用

引用を原稿につながったまま保ちます。

BibTeX ファイルを Markdown の横に置き、inline キーで引用し、必要なときに文献情報を確認して、同じ文書内で参考文献を点検できます。

ローカル引用 workflow

  1. 書誌データを隣に置く

    `.bib` ファイルを Markdown と同じ folder に保存すると、ReadMD が自動的に読み取ります。

  2. 引用キーを書く

    `[@vaswani2017attention]` や `@author2024` の形式で執筆します。

  3. カードを確認

    引用 badge を hover し、利用できる題名、著者、年、掲載先、DOI を確認します。

  4. 参考文献を点検

    文末の参考文献を確認し、修正や再利用が必要な BibTeX 項目をコピーします。

学術引用の質問

どの引用 syntax に対応しますか？

ReadMD は `[@vaswani2017attention]` や `@author2024` のような inline 形式に対応し、一致する項目があれば引用 badge として表示します。

BibTeX ファイルはどこに置きますか？

`.bib` ファイルを Markdown 文書と同じ directory に置くと、近くの書誌データを読み取れます。

引用カードには何を表示できますか？

項目があれば、hover card に論文題名、著者、年、掲載先、DOI link を出し、BibTeX 項目をコピーできます。

文献管理アプリの代わりになりますか？

なりません。既存の BibTeX library を執筆 workflow につなぐ機能です。提出前に項目、指定書式、最終参考文献を確認してください。
