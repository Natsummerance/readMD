表データを整えた Markdown に整理します。

ReadMD はソースとプレビューの両方で表を読みやすく保ちます。列を決め、表を入力または貼り付け、見出し行や数値、例外値を確認してからファイルへ保存します。

ローカル Markdown 表ワークフロー

  1. 列を定義する

    最初に見出し行を書き、各列の意味を一つに限定します。

  2. 行を入力または貼り付け

    直接入力、ビジュアルな表エディター、対応する Excel や CSV からの貼り付け変換を使えます。

  3. 区切りを整える

    共有前にパイプ文字、エスケープされたセル、空欄、列揃えを確認します。

  4. 意味上の例外を確認

    結合セル、単位、数値、日付、注記、空値に明確な Markdown 表現を与えます。

Markdown 表のよくある質問

ReadMD で Markdown 表を作れますか？

はい。ReadMD にはビジュアルな表エディターがあり、Markdown を正として行列を作成できます。

Excel や CSV を Markdown 表にできますか？

ReadMD は Excel と CSV の貼り付けから Markdown 表への変換に対応します。貼り付け後に見出し、区切り、改行、列順を確認してください。

表の編集で自動的にファイルが変わりますか？

いいえ。表示だけの修復はメモリー内です。明示的に編集して保存したときだけ変更がファイルに書き込まれます。

複雑なスプレッドシートはどう扱いますか？

Markdown に直接対応しない結合セルは分割するか注記します。公開前に数値書式、日付、脚注、空欄を確認してください。
