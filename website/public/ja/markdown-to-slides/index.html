スライドを作り直さず Markdown を発表。

執筆、レビュー、履歴、本番を一つの権威あるファイルにまとめます。見出しが構造を作り、技術内容は書いた場所に留まります。

単一ソース発表ワークフロー

  1. まず一つ書く

    見出し、本文、リスト、数式、コード、図、表、参考文献を同じ Markdown 文書に準備します。

  2. Reveal 発表を開く

    発表モードはその文書から始まり、章を別スライドへコピーすることを求めません。

  3. 技術内容を説明する

    見出しが切り替えになり、コード、数式、図、表はそれぞれの説明と接続されたままです。

  4. リハーサルで直す

    フローティング操作バーにはテーマ、文字サイズ、ナビゲーションがあります。修正は同じソースへ戻ります。

発表者の質問

PowerPoint を使わず Markdown を発表できますか？

できます。ReadMD は Reveal ベースのモードで Markdown をそのまま発表するため、技術発表や講義資料に別スライドは必須ではありません。

発表時にどの Markdown 要素が残りますか？

見出しが切り替えになり、コード、数式、図、表、周囲の説明は文脈を保ちます。

リハーサル中に編集できますか？

できます。直前の編集も同じ Markdown ファイルに保存でき、次の発表で使えます。

すべての専用スライド製品を置き換えますか？

いいえ。Markdown を正として管理する人向けです。複雑な独自モーション設計には専用デザインツールが必要な場合があります。
