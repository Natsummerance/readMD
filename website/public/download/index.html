Open-Source System Trust & Installation Guidance

All ReadMD builds are created transparently through public GitHub Actions CI. Unsigned community binaries may trigger OS security dialogs on initial launch:

  • Windows: On Microsoft Defender SmartScreen, click "More info" and select "Run anyway".
  • macOS: If blocked by Gatekeeper, right-click the app icon and select "Open", or run xattr -d com.apple.quarantine ReadMD.app in terminal.
  • Linux: Grant execution permissions before launching AppImage via chmod +x ReadMD-linux-*.AppImage.
