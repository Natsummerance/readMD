Open Source Security & Trust Notice

ReadMD releases are built via public GitHub Actions CI. Because community builds are unsigned, your OS may display a security prompt on first launch:

  • Windows: Click "More info" then "Run anyway" if Microsoft Defender SmartScreen appears.
  • macOS: If Gatekeeper blocks the app, right-click the application icon and select "Open", or run xattr -d com.apple.quarantine ReadMD.app in Terminal.
  • Linux: Run chmod +x ReadMD-linux-*.AppImage before executing the AppImage binary.
