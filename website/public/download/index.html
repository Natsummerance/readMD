Download ReadMD.

The current public prerelease is version 2.3.7-beta.4. Packages are served by GitHub Releases; verify your download against SHA256SUMS.txt before installing.

Windows

Choose the installer for a normal desktop setup, or the portable executable when installation is not allowed. Both are x64 builds.

Windows installer · Windows portable

macOS

Use Apple Silicon packages on M-series Macs and the Intel package for x86_64 Macs. Unzip, then follow macOS gatekeeper guidance if prompted.

Apple Silicon zip · Intel zip

Linux and Chinese systems

AppImage works across common x86_64 distributions; Deb packages integrate with Debian-based systems including UOS and Kylin OS.

x86_64 AppImage · ARM64 AppImage · AMD64 Deb · ARM64 Deb

Editor, MCP, and HarmonyOS

The VS Code extension brings synchronized preview and syntax repair into the editor. The MCP Server connects compatible AI tools. HarmonyOS support is available as an ArkTS source project for DevEco Studio; no prebuilt HAP is provided.

VS Code extension · MCP Server · HarmonyOS source project
