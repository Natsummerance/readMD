Questions, answered.

How does ReadMD open long Markdown files?

ReadMD activates semantic pagination when a document exceeds roughly 8,000 lines or 500 KB. The outline, full-text search, formulas, and page controls remain linked, so readers can move through very large notes without waiting for the whole file to render at once.

Does automatic repair change my Markdown?

No. ReadMD applies syntax recovery only to the in-memory display layer. Missing table separator rows, unclosed markers, and formula formatting issues are corrected visually, while the original Markdown bytes remain exactly as stored until you explicitly save an edit.

Can ReadMD replace slide software?

For technical talks and course material, ReadMD presents the same Markdown used for writing and review. Reveal-based presentation mode preserves headings, math, diagrams, and code, so a last-minute edit does not require copying content into a separate deck.

Which platforms does ReadMD support?

ReadMD V0.0.4 provides Windows x64, macOS Intel and Apple Silicon, and Linux x86_64 packages. VS Code and MCP use the installed Rust engine. UOS and Kylin still require native installation testing.

Is ReadMD private?

Core reading, editing, pagination, OCR, and file conversion are designed to run locally. Documents do not need a cloud account. Optional web fetching and sharing are explicit actions; LAN sharing is intended for devices on the same network.

What license does ReadMD use?

ReadMD is released under the MIT license. Source code, release downloads, checksum lists, and platform-specific packages are published in the public GitHub repository at Natsummerance/readMD.
