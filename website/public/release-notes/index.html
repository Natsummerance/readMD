What changed in ReadMD v2.3.9.

ReadMD v2.3.9 is published through the self-use channel. It introduces the CC0 Arch-Chan Live2D reading companion, native vector PDF editing with MCP tooling, offline Word .doc and complex table reconstruction, kernel security auditing, and complete 46-language alignment.

Release highlights and boundaries

  1. Live2D desktop companion

    CC0 Arch-Chan Live2D reading companion with high-DPI retina scaling, process watchdogs, hit testing, drag-to-open, and 46-language dialogue coverage.

  2. Native vector PDF & MCP tools

    Native vector PDF editing engine for high-fidelity text repair, plus expanded ReadMD MCP Server tools for external AI agent integration.

  3. Offline Word & complex tables

    Pure Python Word .doc binary parsing (FIB/CLX) without COM dependencies, paired with flyingmouse clustering for complex multi-span tables.

  4. Hardened kernel & clean UI

    64-bit Windows Job Objects, POSIX selector deadlines, SQL sandbox isolation, elimination of UI hardcoded emoji with vector SVG icons, and 46-language dictionary alignment.

v2.3.9 release questions

Is v2.3.9 a stable release?

Yes. v2.3.9 was published on GitHub as a stable release, not a prerelease, on 2026-09-10. It ships via the READMD_SELF_USE_RELEASE self-use channel: assets are unsigned and the native platform evidence list is informational, so keep backups and verify SHA256SUMS.txt before installation.

Does display repair change my Markdown?

No. Rendering repairs affect the in-memory display. Source bytes change only when you explicitly edit and save the document.

How are updates checked?

Updates come from official GitHub Release assets into a fixed directory, use temporary files and SHA-256 verification, then publish atomically and recheck before execution.

Which platforms receive packages?

Stable packages target Windows 10/11 (x64/ARM64), macOS 13+ (Intel and Apple Silicon), and Linux x86_64/ARM64 on Ubuntu 22.04/24.04 and Debian 12. UOS, Kylin, and Deepin still lack native evidence and are not formal support commitments; HarmonyOS/OpenHarmony is out of scope for v2.3.9.
