打开超长 Markdown，不让界面冻结。

ReadMD 只对显示层分段，源文件仍然是权威产物。你可以在目录、搜索、公式和页面控件保持联动的情况下继续阅读。

本地阅读工作流

  1. 打开文件

    双击 Markdown 文件，或在 ReadMD 中选择它。阅读始终从本地来源开始。

  2. 让分页启动

    接近 8,000 行或 500 KB 时，语义分页会启用，界面不必等所有节点渲染完成。

  3. 带着上下文跳转

    在章节之间移动或继续滚动时，目录、全文搜索、公式和页面控件保持连接。

  4. 修复但不重写

    缺失表格分隔行和格式错误的加粗可在显示层修正。只有明确编辑并保存后，源文件才会变化。

读者最先问的问题

多大的 Markdown 文件算超大？

在 ReadMD 中，约 8,000 行或 500 KB 时语义分页开始变得相关。具体位置会随文档结构和设备资源变化。

分页会改变我的 Markdown 文件吗？

不会。分页只改变显示方式。除非你主动编辑并保存，原始字节保持不变。

长文档还能搜索和导航吗？

可以。视图分段时，目录、全文搜索、公式渲染和页面控件仍然联动。

阅读时会把文档上传吗？

不会。核心阅读、分页和显示修复设计为本地运行，不需要云账号。
