把既有文档转入 Markdown。

报告、幻灯片、表格、论文、网页和扫描页可以在本地变成可编辑 Markdown，不必经过浏览器上传。

本地转换工作流

  1. 准备来源

    把 DOCX、PPTX、XLSX、PDF、HTML 或 LaTeX 文件保存在本机。

  2. 导入文件

    添加一个文件、多个文件或受支持的文件夹；批量处理支持拖拽。

  3. 转换为 Markdown

    运行转换器，然后把生成的 Markdown 放在原始来源旁查看。

  4. 复核结构

    发布或继续编辑前，检查标题、列表、表格、公式、图片引用和扫描识别结果。

转换常见问题

ReadMD 能把哪些格式转为 Markdown？

ReadMD 可将 DOCX、PPTX、XLSX、PDF、HTML 和 LaTeX 来源转换为 Markdown。网页提取属于可选功能，只在用户明确请求时访问网址。

DOCX 和 PDF 能离线转换吗？

在受支持的平台可以。本地文件转换不需要云账号，也不需要把文档上传到网页表单。

会保留哪些文档结构？

转换器尽量保留标题、列表、表格、引言、公式和图片引用等有用的 Markdown 结构，并移除不必要的专有包装。

转换后的版式会和原来完全一样吗？

不会。专有版式不一定有一一对应的 Markdown 表达。转换后应复核标题、表格、公式和图片，复杂设计尤其需要人工检查。
