让引用始终连接你的草稿。

把 BibTeX 文件放在 Markdown 旁边，用内联键引用，按需查看文献信息，并在同一份文档里复核参考文献。

本地引用工作流

  1. 放好参考文献

    把 `.bib` 文件保存在 Markdown 文档同一文件夹，ReadMD 会自动扫描它。

  2. 写入引用键

    写作时使用 `[@vaswani2017attention]` 或 `@author2024` 这样的内联格式。

  3. 检查卡片

    悬停引用徽章，查看可用的标题、作者、年份、期刊会议和 DOI 信息。

  4. 复核参考文献

    检查文末汇总的参考文献区，必要时复制 BibTeX 来修正或复用条目。

学术引用常见问题

ReadMD 支持哪些引用语法？

ReadMD 支持 `[@vaswani2017attention]` 或 `@author2024` 这类内联写法；当匹配条目可用时会渲染成引用徽章。

BibTeX 文件应该放在哪里？

把 `.bib` 文件和 Markdown 文档放在同一目录，ReadMD 就能扫描相邻的参考文献库。

引用卡片可以显示哪些信息？

在字段可用时，悬浮卡片可以显示论文标题、作者、年份、期刊或会议、DOI 链接，并支持复制 BibTeX 条目。

这会替代文献管理器吗？

不会。它把现有 BibTeX 库连接到写作流程；提交前仍应检查条目、期刊格式要求和最终参考文献区。
