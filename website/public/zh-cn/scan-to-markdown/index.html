在 Windows 和 macOS 上，ReadMD 调用操作系统原生识别引擎。扫描来源留在设备本地，识别结果可以先复核再保存。

本地 OCR 工作流

  1. 准备扫描件

    使用保存在本地的清晰图片或 PDF 页面。页面端正、文字清楚时通常更容易获得干净结果。

  2. 添加或粘贴来源

    在 ReadMD 中添加扫描件，或使用剪贴板工作流提取粘贴截图中的文字。

  3. 本地识别

    Windows 使用 WinRT OCR，macOS 使用 Apple Vision 离线识别。这些路径不需要云账号。

  4. 复核并保存 Markdown

    修正阅读顺序、标题、表格、图注、人名和数字后，再保存或继续编辑 Markdown。

OCR 常见问题

哪些平台支持离线 OCR？

ReadMD 在 Windows 上通过 WinRT、在 macOS 上通过 Apple Vision 支持本地离线识别。实际可用性取决于操作系统和设备能力。

能从截图提取文字吗？

在受支持的平台可以。ReadMD 提供剪贴板工作流，可提取粘贴截图中的文字，不需要发送到网页服务。

OCR 能完美保留表格和版式吗？

不能。识别质量受扫描清晰度、语言、字体和版式复杂度影响。提取后应复核标题、表格、数字、人名和阅读顺序。

识别时会把扫描页上传吗？

不会。经过限定的 Windows 和 macOS OCR 路径设计为本地运行，不需要云账号。
