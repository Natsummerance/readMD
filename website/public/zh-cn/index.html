你可能关心的事

ReadMD 怎么打开超长 Markdown？

当文档超过约 8,000 行或 500 KB，ReadMD 会启动语义分页。目录、全文搜索、公式和页面控件仍然联动，因此读者可以继续滚动和跳转，不必等整个文件一次性渲染。

自动修正会改原文件吗？

不会。语法恢复只作用于内存中的显示层。缺失表格分隔行、未闭合符号和公式排版问题会被视觉修正，原始 Markdown 字节保持不变，直到你主动保存编辑。

能替代幻灯片软件吗？

对技术分享和课程材料可以。ReadMD 的放映模式直接使用写作和评审用的同一条 Markdown，标题、数学、图表和代码保留在原处，临时修改后不用再复制到另一个演示文稿。

支持哪些系统？

ReadMD V0.0.4 提供 Windows x64、macOS Intel / Apple Silicon 和 Linux x86_64 安装包。VS Code 与 MCP 共用已安装的 Rust 内核；统信 UOS、银河麒麟仍需原生安装验收。

数据私密吗？

核心阅读、编辑、分页、OCR 和转换设计为本地运行，文档不需要云账号。网页抓取和共享都是显式操作；局域网共享面向同一 Wi-Fi 内的设备。

采用什么许可证？

ReadMD 使用 MIT 许可证发布。源码、发行包、校验清单和平台资产都在公开仓库 Natsummerance/rust-ReadMD 中。
