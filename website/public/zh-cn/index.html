ReadMD 是什么？

ReadMD 是一个不需要云端账号的跨平台 Markdown 应用。双击 `.md` 就能阅读；编辑时可同时看到实时预览；Word、PPT、Excel、PDF、HTML 和 LaTeX 能转入 Markdown；完成后还能直接放映。长文档按语义分页，目录、搜索和公式保持联动。自动修正如缺表格分隔线或未闭合符号只发生在内存渲染层。AI 助手、文献引用卡、离线 OCR、禅模式和局域网共享围绕同一个文件工作。

关于 ReadMD 的直接回答

ReadMD 怎么打开超长 Markdown？

当文档超过约 8,000 行或 500 KB，ReadMD 会启动语义分页。目录、全文搜索、公式和页面控件仍然联动，因此读者可以继续滚动和跳转，不必等整个文件一次性渲染。

自动修正会改原文件吗？

不会。语法恢复只作用于内存中的显示层。缺失表格分隔行、未闭合符号和公式排版问题会被视觉修正，原始 Markdown 字节保持不变，直到你主动保存编辑。

能替代幻灯片软件吗？

对技术分享和课程材料可以。ReadMD 的放映模式直接使用写作和评审用的同一条 Markdown，标题、数学、图表和代码保留在原处，临时修改后不用再复制到另一个演示文稿。

支持哪些系统？

提供 Windows 7 到 11、Apple Silicon 和 Intel macOS、Linux AppImage/Deb 包，以及统信 UOS 和银河麒麟版本。VSCode 插件和 MCP Server 可连接编辑器与 AI 工具。

数据私密吗？

核心阅读、编辑、分页、OCR 和转换设计为本地运行，文档不需要云账号。网页抓取和共享都是显式操作；局域网共享面向同一 Wi-Fi 内的设备。
