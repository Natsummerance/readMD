把 PDF 变成可编辑 Markdown。

文字型报告、论文、手册和扫描页可以在本地进入 Markdown。来源文件保留在你的设备上，可复用的结构继续保留。

本地 PDF 转换工作流

  1. PDF 保留在本机

    把来源 PDF 放到设备上，先判断它是文字型还是扫描型。

  2. 导入文件

    把 PDF 添加到 ReadMD；多个文档需要同一轮复核时可批量导入。

  3. 转换为 Markdown

    运行转换器，并把结果放在原始 PDF 旁查看。

  4. 保存前复核

    检查标题、列表、表格、阅读顺序、公式、题注和图片引用，再编辑或发布。

PDF 转换常见问题

ReadMD 能转换哪些 PDF？

ReadMD 转换器接受 PDF 来源。文字型文档通常更容易映射为 Markdown；扫描页应在受支持平台使用合格的本地 OCR 工作流。

PDF 转换会上传我的文件吗？

不会。本地 PDF 转换设计为不需要云账号，也不经过浏览器上传表单。

会保留哪些 Markdown 结构？

只要 PDF 提供可恢复的结构，转换器尽量保留标题、列表、表格、引言、公式和图片引用。

每个扫描 PDF 都能完美转换吗？

不能。OCR 质量受清晰度、语言、字体和版式复杂度影响。保存前应复核名称、数字、表格、题注和阅读顺序。
