真实 Markdown 工作流怎么处理。

以下是选择本地 Markdown 工具前最常见的问题：超长文件、既有办公文档、扫描页、学术引用，以及不重做幻灯片。

超过 8,000 行的 Markdown 怎么读？

把文件放进 ReadMD。接近 8,000 行或 500 KB 时会启用语义分页，界面不必等待所有段落一次渲染；目录、全文搜索、公式和页面控件仍然联动。

DOCX、PDF、HTML 或 LaTeX 能转 Markdown 吗？

可以。转换工作流支持 Word、PowerPoint、Excel、PDF、HTML 和 LaTeX 导入，保留标题、列表、表格、引言、公式和图片引用等结构。复杂专有版式转换后仍应复核。

扫描件能不上传就提取文字吗？

在受支持的平台可以。ReadMD 调用操作系统原生 OCR 在本地识别，之后在 Markdown 中修正标题和表格。这条本地路径不需要云账号。

能不重做幻灯片直接讲吗？

可以。继续用 Markdown 写作，准备好后打开基于 Reveal 的放映模式；代码、数学、图表和表格保留上下文，临时修改也回到同一份文件。

哪些系统可以运行？

ReadMD v2.3.8 正式版面向 Windows 10/11、macOS 13+ 与 Linux x86_64/ARM64。统信 UOS、银河麒麟等国产系统的安装包仍缺原生证据，不构成正式支持承诺；VSCode 插件与 FastMCP Server 可连接编辑器和兼容 AI 工具。
