把表格资料整理成干净的 Markdown。

ReadMD 让表格在源码和预览中都保持可读。可以先建立字段，再粘贴表格内容，最后检查标题行、数值和边界情况，确认后才会写入文件。

本地 Markdown 表格工作流

  1. 定义字段

    先写标题行，让每一列都有清晰且唯一的业务含义。

  2. 输入或粘贴行

    直接添加内容，使用表格设计器，或把受支持的 Excel 和 CSV 内容粘贴转换为 Markdown。

  3. 规范分隔符

    分享前检查竖线、转义单元格、空白字段和列对齐。

  4. 复核语义边界

    为合并单元格、单位、数字、日期、注释和空值安排明确的 Markdown 表达。

Markdown 表格常见问题

ReadMD 能创建 Markdown 表格吗？

可以。ReadMD 提供可视化表格设计器，可以在保持 Markdown 为权威格式的同时构建行和列。

Excel 或 CSV 能变成 Markdown 表格吗？

ReadMD 支持把 Excel 和 CSV 粘贴转换为 Markdown 表格。粘贴后应复核表头、分隔符、换行和字段顺序。

编辑表格会自动改写我的文件吗？

不会。显示层修复保留在内存中；只有你明确编辑并保存时，Markdown 变更才会写入文件。

复杂电子表格应该怎么处理？

对 Markdown 没有直接表达的合并单元格应拆平或加注。发布前检查数字格式、日期、脚注和空值状态。
