ReadMD v2.3.9 改了什么。

ReadMD v2.3.9 是自用通道发布的正式版：推出 CC0 许可的 Arch-Chan Live2D 桌面伴读桌宠，新增原生矢量 PDF 编辑器与 FastMCP 工具链，强化纯 Python Word .doc 与复杂表格聚类重构，完成多项内核与沙箱安全审计，实现前端全面去 Emoji 与 46 种语言 100% 对齐。

发布亮点与边界

  1. Live2D 桌面伴读宠物

    集成 CC0 许可 Arch-Chan Live2D 模型，支持高 DPI 视网膜缩放、双向看门狗、命中测试、拖拽文件即开读以及 46 种语言气泡对话。

  2. 原生矢量 PDF 与 MCP 工具

    内置原生高保真矢量 PDF 编辑引擎，扩展 MCP Server 审阅与标注工具，全面赋能外部 Agent 集成。

  3. 离线 Word 与复杂表格

    纯 Python 解析 Word .doc 二进制流（FIB/CLX），摆脱 COM 依赖；引入复杂表格聚类重建跨行跨列结构。

  4. 内核沙箱加固与纯净体验

    64 位 Windows Job Object、POSIX 选择器剩余超时等待、SQL 沙箱隔离，前端全面去硬编码 Emoji 升级矢量 SVG 并达成 46 种语言词条对齐。

v2.3.9 正式版常见问题

v2.3.9 是正式版吗？

是。v2.3.9 已于 2026-09-10 在 GitHub 以正式发布（非预发布）形式上线，经 READMD_SELF_USE_RELEASE 自用通道发布：资产未做签名，原生平台证据清单按参考口径提供；安装前请保留备份并核对 SHA256SUMS.txt。

显示修复会改写我的 Markdown 吗？

不会。渲染修复只影响内存中的显示层；只有你明确编辑并保存时，源文件字节才会变化。

更新包如何检查？

更新只来自官方 GitHub Release 资产，先进入固定目录和临时文件，经 SHA-256 校验后原子发布，并在执行前复核。

哪些平台会收到安装包？

正式版安装包覆盖 Windows 10/11（x64/ARM64）、macOS 13+（Intel 与 Apple Silicon），以及 Ubuntu 22.04/24.04 和 Debian 12 的 Linux x86_64/ARM64；统信 UOS、银河麒麟与 Deepin 仍缺原生证据，不构成正式支持承诺；HarmonyOS/OpenHarmony 不在 v2.3.9 范围内。
