ReadMD v2.3.7 改了什么。

这个测试版收紧放映隔离和更新完整性，优化启动资源加载与标签反馈；你的 Markdown 仍然是权威源文件。

发布亮点与边界

  1. 更安全的放映路径

    应用内 Reveal.js 只加载同源离线资源；幻灯片 HTML 继续通过白名单净化。

  2. 完整性优先更新

    官方资产下载到固定目录，通过 SHA-256 后原子发布，执行前再次复核。

  3. 更轻的交互加载

    入口脚本分阶段加载，共享资源按需引入，静态响应支持 ETag 复验，搜索 Enter 保持焦点。

  4. 更清楚的标签状态

    选中和 ARIA 状态立即刷新，过期渲染结果被丢弃，溢出时定位活动标签，Zen 模式保持一致的 Escape 路径。

V2.3.7 验收候选常见问题

v2.3.7 是正式版吗？

当前页面描述的是验收候选，需等所有必需的平台证据完成后才可作为正式版；请在安装前保留备份并校验 SHA-256。

显示修复会改写我的 Markdown 吗？

不会。渲染修复只影响内存中的显示层；只有你明确编辑并保存时，源文件字节才会变化。

更新包如何检查？

更新只来自官方 GitHub Release 资产，先进入固定目录和临时文件，经 SHA-256 校验后原子发布，并在执行前复核。

哪些平台会收到安装包？

候选目标包含 Windows、Intel 与 Apple Silicon macOS、Linux x86_64/ARM64、UOS、麒麟和 Deepin；每个平台完成原生证据后才会确认安装包与正式支持。HarmonyOS/OpenHarmony 不属于 v2.3.7。
