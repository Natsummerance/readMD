不重做幻灯片，直接讲 Markdown。

写作、评审、仓库历史和现场讲解共用一份权威文件。标题负责结构，技术内容留在原来的位置。

单一来源放映工作流

  1. 先写一份源文件

    在同一个 Markdown 文档中准备标题、正文、列表、公式、代码、图表、表格和参考文献。

  2. 打开 Reveal 放映

    放映模式从这份文档启动，不会要求你把章节复制到另一个演示文稿。

  3. 讲清技术细节

    标题提供过渡，代码、数学、图表和表格仍然连接着它们的解释。

  4. 彩排时直接修订

    浮动工具栏提供主题、字体缩放和导航控制；修改会回到同一份源文件。

演讲者常问的问题

Markdown 能不放 PowerPoint 直接讲吗？

可以。ReadMD 使用基于 Reveal 的模式直接放映 Markdown，技术分享和课程材料不需要另一套幻灯片。

放映时哪些 Markdown 元素会保留？

标题成为过渡；代码、数学记号、图表、表格以及周围说明文字都保留上下文。

彩排时还能修改吗？

可以。临场或彩排修改可以写回同一份 Markdown 文件，下一次放映直接使用。

这能替代所有专业幻灯片工具吗？

不能。它适合以 Markdown 为权威来源的人。复杂定制动画设计仍可能需要专门设计工具。
