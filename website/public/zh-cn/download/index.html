开源软件包系统信任与安装指引

ReadMD 所有版本均通过 GitHub Actions 公开流水线透明构建。因社区构建未购买商业签名，首次启动时操作系统可能弹出安全提示：

  • Windows：若弹出 Microsoft Defender SmartScreen，点击「更多信息」并选择「仍要运行」即可。
  • macOS：若遇 Gatekeeper 拦截，请右键点击应用图标选择「打开」，或在终端运行 xattr -d com.apple.quarantine ReadMD.app 移除隔离属性。
  • Linux：运行 AppImage 格式前需在终端执行 chmod +x ReadMD-linux-*.AppImage 赋予执行权限。
