讓引用始終連接你的草稿。

把 BibTeX 檔案放在 Markdown 旁邊，用內嵌鍵引用，按需查看文獻資訊，並在同一份文件裡複核參考文獻。

本機引用工作流程

  1. 放好參考文獻

    把 `.bib` 檔案保存在 Markdown 文件同一資料夾，ReadMD 會自動掃描它。

  2. 寫入引用鍵

    寫作時使用 `[@vaswani2017attention]` 或 `@author2024` 這樣的內嵌格式。

  3. 檢查卡片

    懸停引用徽章，查看可用的標題、作者、年份、期刊會議和 DOI 資訊。

  4. 複核參考文獻

    檢查文末彙整的參考文獻區，必要時複製 BibTeX 來修正或重複使用項目。

學術引用常見問題

ReadMD 支援哪些引用語法？

ReadMD 支援 `[@vaswani2017attention]` 或 `@author2024` 這類內嵌寫法；當匹配項目可用時會渲染成引用徽章。

BibTeX 檔案應該放在哪裡？

把 `.bib` 檔案和 Markdown 文件放在同一目錄，ReadMD 就能掃描相鄰的參考文獻庫。

引用卡片可以顯示哪些資訊？

在欄位可用時，懸浮卡片可以顯示論文標題、作者、年份、期刊或會議、DOI 連結，並支援複製 BibTeX 項目。

這會替代文獻管理器嗎？

不會。它把現有 BibTeX 庫連接到寫作流程；提交前仍應檢查項目、期刊格式要求和最終參考文獻區。
