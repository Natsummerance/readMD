把既有文件轉入 Markdown。

報告、簡報、試算表、論文、網頁和掃描頁可以在本機變成可編輯 Markdown，不必經過瀏覽器上傳。

本機轉換工作流程

  1. 準備來源

    把 DOCX、PPTX、XLSX、PDF、HTML 或 LaTeX 檔案保存在本機。

  2. 匯入檔案

    新增一個檔案、多個檔案或受支援的資料夾；批次處理支援拖放。

  3. 轉換為 Markdown

    執行轉換器，然後把產生的 Markdown 放在原始來源旁查看。

  4. 複核結構

    發布或繼續編輯前，檢查標題、列表、表格、公式、圖片參照和掃描識別結果。

轉換常見問題

ReadMD 能把哪些格式轉為 Markdown？

ReadMD 可將 DOCX、PPTX、XLSX、PDF、HTML 和 LaTeX 來源轉換為 Markdown。網頁擷取屬於可選功能，只在使用者明確請求時連線。

DOCX 和 PDF 能離線轉換嗎？

在受支援的平台可以。本機檔案轉換不需要雲端帳號，也不需要將文件上傳到網頁表單。

會保留哪些文件結構？

轉換器盡量保留標題、列表、表格、引言、公式和圖片參照等有用的 Markdown 結構，並移除不必要的專有包裝。

轉換後的版式會和原來完全一樣嗎？

不會。專有版式不一定有一對一的 Markdown 表達。轉換後應複核標題、表格、公式和圖片，複雜設計尤其需要人工檢查。
