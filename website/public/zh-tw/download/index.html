開源軟體套件系統信任與安裝指引

ReadMD 所有版本均透過 GitHub Actions 公開流水線透明建置。因社群建置未購買商業簽章，首次啟動時作業系統可能彈出安全提示：

  • Windows：若彈出 Microsoft Defender SmartScreen，點擊「詳細資訊」並選擇「仍要執行」即可。
  • macOS：若遇 Gatekeeper 攔截，請右鍵點擊應用圖示選擇「開啟」，或在終端機執行 xattr -d com.apple.quarantine ReadMD.app 移除隔離屬性。
  • Linux：執行 AppImage 格式前需在終端機執行 chmod +x ReadMD-linux-*.AppImage 賦予執行權限。
