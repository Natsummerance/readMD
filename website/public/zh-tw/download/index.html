開箱即用的 5 大核心 MCP Tools

readmd_fix_markdown

自動偵測並記憶體自我修復 LaTeX 語法、未閉合圍欄、錯位表格與標點空格。

readmd_convert_to_markdown

一鍵將 PDF、Word (.docx)、PPTX、Excel 與 TeX 文件擷取為標準 Markdown。

readmd_latex_to_md

將學術論文 LaTeX 原始碼完整轉換為符合 GFM 規範的高品質 Markdown。

readmd_md_to_latex

將 Markdown 筆記即時編譯匯出為可直接由 TeXLive / Overleaf 編譯的學術論文程式碼。

readmd_parse_bibtex

深度解析 .bib 文獻資料庫，快速擷取作者、年份與標準 Citation 引用標註。

開源軟體包系統信任與安裝指引

ReadMD 所有版本均透過 GitHub Actions 公開流水線透明建置。因社群建置未購買商業簽章，首次啟動時作業系統可能彈出安全提示：

  • Windows：若彈出 Microsoft Defender SmartScreen，點擊「詳細資訊」並選擇「仍要執行」即可。
  • macOS：若遇 Gatekeeper 攔截，請右鍵點擊應用圖示選擇「開啟」，或在終端機執行 xattr -d com.apple.quarantine ReadMD.app 移除隔離屬性。
  • Linux：執行 AppImage 格式前需在終端機執行 chmod +x ReadMD-linux-*.AppImage 賦予執行權限。
