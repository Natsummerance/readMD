不重做簡報，直接講 Markdown。

寫作、審閱、儲存庫歷史和現場報告共用一份權威檔案。標題負責結構，技術內容留在原本位置。

單一來源放映工作流程

  1. 先寫一份原始檔

    在同一個 Markdown 文件中準備標題、正文、列表、公式、程式碼、圖表、表格和參考文獻。

  2. 開啟 Reveal 放映

    放映模式從這份文件啟動，不會要求你把章節複製到另一份簡報。

  3. 講清技術細節

    標題提供過渡，程式碼、數學、圖表和表格仍然連接著它們的解釋。

  4. 排練時直接修訂

    浮動工具列提供主題、字體縮放和導覽控制；修改會回到同一份原始檔。

演講者常問的問題

Markdown 能不經 PowerPoint 直接報告嗎？

可以。ReadMD 使用基於 Reveal 的模式直接放映 Markdown，技術分享和課程教材不需要另一套簡報。

放映時哪些 Markdown 元素會保留？

標題成為過渡；程式碼、數學記號、圖表、表格以及周圍說明文字都保留上下文。

排練時還能修改嗎？

可以。臨場或排練修改可以寫回同一份 Markdown 檔案，下一次放映直接使用。

這能替代所有專業簡報工具嗎？

不能。它適合以 Markdown 為權威來源的人。複雜客製動態設計仍可能需要專門設計工具。
