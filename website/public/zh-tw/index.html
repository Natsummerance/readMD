ReadMD 是什麼？

ReadMD 是一個不需要雲端帳號的跨平台 Markdown 應用。雙擊 `.md` 即可閱讀；編輯時可同時檢視即時預覽；Word、PPT、Excel、PDF、HTML 和 LaTeX 能轉入 Markdown；完成後還能直接放映。長文件依語意分頁，目錄、搜尋和公式保持連動。自動修正如缺少表格分隔線或未閉合符號只發生在記憶體渲染層。AI 助手、文獻引用卡、離線 OCR、禪模式與區域網路共用圍繞同一個檔案運作。

關於 ReadMD 的直接回答

ReadMD 如何開啟超長 Markdown？

當文件超過約 8,000 行或 500 KB，ReadMD 會啟動語意分頁。目錄、全文搜尋、公式和頁面控制項仍然連動，讀者可以繼續滾動和跳轉，不需等待整份文件一次渲染。

自動修正會改原始檔嗎？

不會。語法修復只作用於記憶體中的顯示層。缺少表格分隔列、未閉合符號和公式排版問題會被視覺修正，原始 Markdown 位元組保持不變，直到你主動儲存編輯。

能取代簡報軟體嗎？

對技術分享和課程教材可以。ReadMD 的放映模式直接使用寫作與審閱用的同一條 Markdown，標題、數學、圖表和程式碼保留在原處，臨時修改後不必複製到另一份簡報。

支援哪些系統？

提供 Windows 7 到 11、Apple Silicon 與 Intel macOS、Linux AppImage/Deb 套件，以及統信 UOS 和銀河麒麟版本。VSCode 擴充套件與 MCP Server 可連接編輯器和 AI 工具。

資料私密嗎？

核心閱讀、編輯、分頁、OCR 和轉換設計為本地執行，文件不需要雲端帳號。網頁擷取和共用都是明確操作；區域網路共用面向同一 Wi-Fi 內的裝置。
