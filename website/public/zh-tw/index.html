你可能關心的事

ReadMD 如何開啟超長 Markdown？

當文件超過約 8,000 行或 500 KB，ReadMD 會啟動語意分頁。目錄、全文搜尋、公式和頁面控制項仍然連動，讀者可以繼續滾動和跳轉，不需等待整份文件一次渲染。

自動修正會改原始檔嗎？

不會。語法修復只作用於記憶體中的顯示層。缺少表格分隔列、未閉合符號和公式排版問題會被視覺修正，原始 Markdown 位元組保持不變，直到你主動儲存編輯。

能取代簡報軟體嗎？

對技術分享和課程教材可以。ReadMD 的放映模式直接使用寫作與審閱用的同一條 Markdown，標題、數學、圖表和程式碼保留在原處，臨時修改後不必複製到另一份簡報。

支援哪些系統？

ReadMD V0.0.4 提供 Windows x64、macOS Intel / Apple Silicon 與 Linux x86_64 安裝套件。VS Code 與 MCP 共用已安裝的 Rust 核心；統信 UOS、銀河麒麟仍需原生安裝驗收。

資料私密嗎？

核心閱讀、編輯、分頁、OCR 和轉換設計為本地執行，文件不需要雲端帳號。網頁擷取和共用都是明確操作；區域網路共用面向同一 Wi-Fi 內的裝置。

採用什麼授權？

ReadMD 以 MIT 授權發布。原始碼、發行套件、校驗清單和平臺資產都在公開儲存庫 Natsummerance/readMD 中。
