把掃描件文字擷取成可編輯 Markdown。

在 Windows 和 macOS 上，ReadMD 呼叫作業系統原生辨識引擎。掃描來源留在裝置本機，辨識結果可以先複核再儲存。

本機 OCR 工作流程

  1. 準備掃描件

    使用保存在本機的清晰圖片或 PDF 頁面。頁面端正、文字清楚時通常更容易獲得乾淨結果。

  2. 加入或貼上來源

    在 ReadMD 加入掃描件，或使用剪貼簿工作流程擷取貼上截圖中的文字。

  3. 本機辨識

    Windows 使用 WinRT OCR，macOS 使用 Apple Vision 離線辨識。這些路徑不需要雲端帳號。

  4. 複核並儲存 Markdown

    修正閱讀順序、標題、表格、圖註、人名和數字後，再儲存或繼續編輯 Markdown。

OCR 常見問題

哪些平台支援離線 OCR？

ReadMD 在 Windows 上透過 WinRT、在 macOS 上透過 Apple Vision 支援本機離線辨識。實際可用性取決於作業系統和裝置能力。

能從截圖擷取文字嗎？

在受支援的平台可以。ReadMD 提供剪貼簿工作流程，可擷取貼上截圖中的文字，不需要傳送到網頁服務。

OCR 能完美保留表格和版式嗎？

不能。辨識品質受掃描清晰度、語言、字體和版式複雜度影響。擷取後應複核標題、表格、數字、人名和閱讀順序。

辨識時會把掃描頁上傳嗎？

不會。經過限定的 Windows 和 macOS OCR 路徑設計為本機執行，不需要雲端帳號。
