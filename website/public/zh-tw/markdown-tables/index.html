把表格資料整理成乾淨的 Markdown。

ReadMD 讓表格在原始碼和預覽中都保持可讀。可以先建立欄位，再貼上表格內容，最後檢查標題列、數值和邊界情況，確認後才會寫入檔案。

本機 Markdown 表格工作流

  1. 定義欄位

    先寫標題列，讓每一欄都有清楚且唯一的業務意義。

  2. 輸入或貼上列

    直接新增內容，使用表格設計器，或把受支援的 Excel 和 CSV 內容貼上轉換為 Markdown。

  3. 規範分隔符

    分享前檢查豎線、跳脫儲存格、空白欄位和欄位對齊。

  4. 覆核語意邊界

    為合併儲存格、單位、數字、日期、註釋和空值安排明確的 Markdown 表示。

Markdown 表格常見問題

ReadMD 能建立 Markdown 表格嗎？

可以。ReadMD 提供視覺化表格設計器，可以在保持 Markdown 為權威格式的同時建立列和欄。

Excel 或 CSV 能變成 Markdown 表格嗎？

ReadMD 支援把 Excel 和 CSV 貼上轉換為 Markdown 表格。貼上後應覆核表頭、分隔符、換行和欄位順序。

編輯表格會自動改寫我的檔案嗎？

不會。顯示層修復保留在記憶體中；只有你明確編輯並儲存時，Markdown 變更才會寫入檔案。

複雜電子表格應該怎麼處理？

對 Markdown 沒有直接表示的合併儲存格應拆平或加註。發布前檢查數字格式、日期、腳注和空值狀態。
