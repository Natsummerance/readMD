開啟超長 Markdown，不讓介面凍結。

ReadMD 只對顯示層分段，原始檔仍是權威產物。目錄、搜尋、公式和頁面控制項保持連動，你可以安心閱讀。

本機閱讀工作流程

  1. 開啟檔案

    雙擊 Markdown 檔案，或在 ReadMD 中選擇它。閱讀始終從本機來源開始。

  2. 讓分頁啟動

    接近 8,000 行或 500 KB 時，語意分頁會啟用，介面不必等所有節點渲染完成。

  3. 帶著上下文跳轉

    在章節之間移動或繼續捲動時，目錄、全文搜尋、公式和頁面控制項保持連接。

  4. 修復但不重寫

    缺少表格分隔列和格式錯誤的粗體可在顯示層修正。只有明確編輯並儲存後，原始檔才會改變。

讀者最先問的問題

多大的 Markdown 檔案算超大？

在 ReadMD 中，約 8,000 行或 500 KB 時語意分頁開始變得相關。實際位置會隨文件結構和裝置資源變化。

分頁會改變我的 Markdown 檔案嗎？

不會。分頁只改變顯示方式。除非你主動編輯並儲存，原始位元組保持不變。

長文件還能搜尋和導覽嗎？

可以。檢視分段時，目錄、全文搜尋、公式渲染和頁面控制項仍然連動。

閱讀時會把文件上傳嗎？

不會。核心閱讀、分頁和顯示修復設計為本機執行，不需要雲端帳號。
