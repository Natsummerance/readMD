ReadMD v2.3.9 改了什麼。

ReadMD v2.3.9 是自用通道發布的正式版：推出 CC0 許可的 Arch-Chan Live2D 桌面伴讀桌寵，新增原生向量 PDF 編輯器與 FastMCP 工具鏈，強化純 Python Word .doc 與複雜表格聚類重構，完成多項核心與沙箱安全稽核，實現前端全數去 Emoji 與 46 種語言 100% 對齊。

發布亮點與邊界

  1. Live2D 桌面伴讀寵物

    整合 CC0 許可 Arch-Chan Live2D 模型，支援高 DPI 視網膜縮放、雙向看門狗、點擊測試、拖曳檔案即開讀以及 46 種語言氣泡對話。

  2. 原生向量 PDF 與 MCP 工具

    內建原生高保真向量 PDF 編輯引擎，擴充 MCP Server 審閱與標註工具，全面賦能外部 Agent 整合。

  3. 離線 Word 與複雜表格

    純 Python 解析 Word .doc 二進位流（FIB/CLX），擺脫 COM 依賴；引入複雜表格聚類重建跨列跨欄結構。

  4. 核心沙箱強化與純淨體驗

    64 位元 Windows Job Object、POSIX 選擇器剩餘逾時等待、SQL 沙箱隔離，前端全數去硬編碼 Emoji 升級向量 SVG 並達成 46 種語言詞條對齊。

v2.3.9 正式版常見問題

v2.3.9 是正式版嗎？

是。v2.3.9 已於 2026-09-10 在 GitHub 以正式發行（非預覽版）形式上線，經 READMD_SELF_USE_RELEASE 自用通道發布：資產未做簽名，原生平台證據清單按參考口徑提供；安裝前請保留備份並核對 SHA256SUMS.txt。

顯示修復會改寫我的 Markdown 嗎？

不會。渲染修復只影響記憶體中的顯示層；只有你明確編輯並儲存時，原始檔位元組才會變化。

更新套件如何檢查？

更新只來自官方 GitHub Release 資產，先進入固定目錄和暫存檔，經 SHA-256 校驗後原子發布，並在執行前複核。

哪些平台會收到安裝套件？

正式版安裝套件涵蓋 Windows 10/11（x64/ARM64）、macOS 13+（Intel 與 Apple Silicon），以及 Ubuntu 22.04/24.04 和 Debian 12 的 Linux x86_64/ARM64；統信 UOS、銀河麒麟與 Deepin 仍缺原生證據，不構成正式支援承諾；HarmonyOS/OpenHarmony 不在 v2.3.9 範圍內。
