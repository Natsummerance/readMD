ReadMD v2.3.8 改了什麼。

ReadMD v2.3.8 是自用通道發布的第一個正式版：批次轉檔合併進統一工作台且隨時可取消，PPTX 與 XLSX 改為原生解析，圖表與壓縮套件處理完成安全強化，46 種語言介面全數收尾。

發布亮點與邊界

  1. 統一批次工作台

    轉檔、OCR 與匯出任務共用一個工作台，任何任務都能取消，結果逐列可追溯。

  2. 原生 OOXML 解析

    PPTX 與 XLSX 直接按檔案格式讀取；舊版 Office 格式會得到明確錯誤提示，而不是莫名失敗。

  3. 圖表與壓縮套件強化

    zip 解壓拒絕路徑穿越與壓縮炸彈；Vega/Vega-Lite 改由伺服器端沙箱渲染且 CSP 不含 unsafe-eval；PlantUML 遠端渲染前需確認；Chart.js 支援離線渲染。

  4. 46 種語言與更穩的擴充

    從系統匣到技能匯入的介面文案涵蓋 46 種語言；VS Code 與 MCP 支援動態技能、串流取消與連線狀態顯示；技能匯入失敗自動回滾。

v2.3.8 正式版常見問題

v2.3.8 是正式版嗎？

是。v2.3.8 已於 2026-09-03 在 GitHub 以正式發行（非預覽版）形式上線，經 READMD_SELF_USE_RELEASE 自用通道發布：資產未做簽名，原生平台證據清單按參考口徑提供；安裝前請保留備份並核對 SHA256SUMS.txt。

顯示修復會改寫我的 Markdown 嗎？

不會。渲染修復只影響記憶體中的顯示層；只有你明確編輯並儲存時，原始檔位元組才會變化。

更新套件如何檢查？

更新只來自官方 GitHub Release 資產，先進入固定目錄和暫存檔，經 SHA-256 校驗後原子發布，並在執行前複核。

哪些平台會收到安裝套件？

正式版安裝套件涵蓋 Windows 10/11（x64/ARM64）、macOS 13+（Intel 與 Apple Silicon），以及 Ubuntu 22.04/24.04 和 Debian 12 的 Linux x86_64/ARM64；統信 UOS、銀河麒麟與 Deepin 仍缺原生證據，不構成正式支援承諾；HarmonyOS/OpenHarmony 不在 v2.3.8 範圍內。
