ReadMD v2.3.7 改了什麼。

這個測試版收緊放映隔離和更新完整性，最佳化啟動資源載入與標籤回饋；你的 Markdown 仍然是權威原始檔。

發布亮點與邊界

  1. 更安全的放映路徑

    應用內 Reveal.js 只載入同源離線資源；投影片 HTML 繼續透過白名單淨化。

  2. 完整性優先更新

    官方資產下載到固定目錄，通過 SHA-256 後原子發布，執行前再次複核。

  3. 更輕的互動載入

    入口腳本分階段載入，共享資源按需引入，靜態回應支援 ETag 複驗，搜尋 Enter 保持焦點。

  4. 更清楚的標籤狀態

    選取和 ARIA 狀態立即重新整理，過期渲染結果被捨棄，溢出時定位活動標籤，Zen 模式保持一致的 Escape 路徑。

V2.3.7 驗收候選常見問題

v2.3.7 是正式版嗎？

目前頁面描述的是驗收候選，需等所有必要的平台證據完成後才可作為正式版；請在安裝前保留備份並校驗 SHA-256。

顯示修復會改寫我的 Markdown 嗎？

不會。渲染修復只影響記憶體中的顯示層；只有你明確編輯並儲存時，原始檔位元組才會變化。

更新套件如何檢查？

更新只來自官方 GitHub Release 資產，先進入固定目錄和暫存檔，經 SHA-256 校驗後原子發布，並在執行前複核。

哪些平台會收到安裝套件？

候選目標包含 Windows、Intel 與 Apple Silicon macOS、Linux x86_64/ARM64、UOS、麒麟與 Deepin；每個平台完成原生證據後才會確認套件與正式支援。HarmonyOS/OpenHarmony 不屬於 v2.3.7。
