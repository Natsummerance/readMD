    🤖 AI 助手

    🖼 插入图片（裁剪 / 缩放 / 旋转）

    请先选择本地图片开始编辑（拖拽虚线框裁剪，右下角手柄调整大小）

    图片将保存到文档同目录的 images/ 子文件夹，并以相对路径插入 Markdown（仅在编辑本地 .md 时可用）。

    📝 Prompt 模板管理

      内置模板可直接编辑并保存（覆盖默认行为）；删除内置模板即恢复默认。{doc} / {prompt} 会在发送时自动替换为文档内容与补充要求。

      📱 移动端共享

      启动后手机连同一 Wi-Fi，扫描二维码即可在手机浏览器阅读当前文档（也支持转 MD / OCR / 网页 / AI）。局域网访问需携带本次随机令牌，关闭共享即失效。

      使用 trafilatura 提取正文，对文章 / 博客 / 新闻类页面效果最佳。
