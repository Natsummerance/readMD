description: Use when a user is creating or revising a ReadMD Skill and needs a test-first writing workflow.
---
Design the Skill with a failing baseline first. Define triggering examples and no-trigger controls, write the smallest instruction set, run representative normal and adversarial cases, then revise only where a failure is observed. Keep descriptions trigger-focused, instructions concise, and references one level deep. Present the final draft, test evidence, and known limits before publishing.
