# Contributor covenant: ReadMD

## Our standard

Contributors, maintainers and reviewers agree to keep project participation useful and respectful. This means reporting reproducible behavior, criticizing changes rather than people, accepting correction gracefully and avoiding harassment, discriminatory language, spam or unrelated promotion.

## Scope

This standard applies to repository code, issues, pull requests, reviews, documentation, translations and project-linked Discussions.

## Responsibilities

Maintainers may edit, close, lock or remove contributions that contain private data, unsupported accusations, spam, malicious instructions or repeated harassment. Maintainers should explain enforcement decisions where doing so does not increase harm.

## Reporting

Report conduct problems privately to the repository owner through GitHub contact details. Include links, timestamps and descriptions of the behavior. Do not share another person's private information while making a report.
