# 📖 ReadMD · 全プラットフォーム対応 軽量 Markdown ビューアー＆エディター

**完全ローカル · 爆速起動 · オフライン対応 · クロスプラットフォーム**

`.md` ファイルをダブルクリックするだけですぐに読める。レンダリング前によくある構文エラー（表崩れ、太字閉じ忘れ、LaTeX 数式、見出しスペース不足）を自動修復します。**元のファイルを書き換えることは一切なく、プレビュー表示のみを最適化します**。内蔵 AI アシスタント、Office/PDF 一括変換、システムネイティブ OCR、Web 抽出、LaTeX PRO 学術強化、Zen 集中モード、ローカル Wi-Fi 共有を統合。
